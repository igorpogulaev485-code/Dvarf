# План слайса: HTTPS для creed20.tech

**Статус:** в плане · **ждём ok** перед работой на VPS  
**Контур:** план → **твой ok** → код/сервер → проверка замочка → прод

**Зачем:** Safari показывает «!» у адреса — сайт открыт по HTTP без шифрования. Нужен HTTPS.

---

## Важно про reg.ru

У рег.ру **есть** бесплатный Let’s Encrypt — но он ставится **на их хостинг** (сайт должен жить у них в ispmanager/cPanel).

У нас: домен в **reg.ru**, сайт на **Timeweb VPS**.  
Кнопка «бесплатный SSL» в панели рег.ру **к нашему серверу не привяжется**.  
Сертификат выпускаем **на VPS**, где реально отвечает nginx/Docker.

## Что делаем на Timeweb VPS

1. Nginx (или reverse-proxy перед Docker): `server_name creed20.tech www.creed20.tech;`
2. Выпуск сертификата Let’s Encrypt (`certbot` / аналог на VPS).
3. Слушать **443**, редирект `http://` → `https://`.
4. Канон: **https://creed20.tech** (www → apex или наоборот — один вариант).
5. Автообновление сертификата (cron/systemd timer).

### Если Let’s Encrypt с VPS в РФ не достучится до API

Запасные варианты (в том же слайсе, без смены домена):

- DNS-01 (TXT в зоне reg.ru) + выпуск с машины, где API доступен;
- бесплатный SSL в панели Timeweb (если дают для своего IP/домена);
- ZeroSSL / другой ACME-провайдер.
