# Часть I. Картина мира за 5 минут

## 1. Что у нас за продукт

Есть приложение (в коде оно зовётся **Dvarf**, для людей снаружи — **creed20**).

Оно умеет две большие вещи:

1. **Справочник** — расы, заклинания, монстры, черты… чтобы не листать бумажную книгу.
2. **Инструмент** — лист персонажа, стол игры, кнопки «надел доспех → КД сам посчитался», каст, бой.

Вы сказали важное: **справочники огромные, выкидывать их не будете.**  
Значит стратегия такая: справочники **оставляем**, а вокруг них строим защиту, чтобы меньше шансов получить претензию.

## 2. Кто вообще может «прийти с претензией»

Представьте две разные жалобы:

### Жалоба А — от создателей D&D (Wizards of the Coast)

Они говорят примерно:  
«Это наши книги. Вы положили наши тексты/монстров/расы в свой сервис.»

### Жалоба Б — от русских сайтов-справочников (ttg.club, dnd.su) или конкурента вроде LSS

Они говорят примерно:  
«Вы не просто „сделали похожий справочник“, вы **скопировали нашу базу / наш API / наши карточки**»  
или «вы скопировали наш продукт целиком».

Это **разные** проблемы. Лечатся **разными** действиями.  
Поэтому в плане несколько «щитов», а не один совет «будьте хорошими».

## 3. Самая важная идея всей стратегии

> **Мы не продаём книги. Мы продаём удобную кнопку «играть».**  
> Книжные данные в продукте есть, но **доступ к ним бесплатный навсегда**.

Почему так:  
если вы берёте деньги **за доступ к чужим текстам**, претензия звучит сильно.  
если вы берёте деньги **за свой инструмент**, а справочник бесплатный «для стола» — позиция гораздо спокойнее (так живут многие фан-проекты; у LSS похожая логика «деньги за инструмент/поддержку»).

**На пальцах:**  
магазин не продаёт чужой учебник как товар на кассе, но даёт бесплатную шпаргалку, а деньги берёт за удобный калькулятор и облако сохранений.

# Часть II. Словарь без боли

Читайте только если встретили слово и оно режет глаз.

| Слово | Простыми словами |
| --- | --- |
| **WotC / Wizards** | Компания-владелец D&D |
| **IP** | «Интеллектуальная собственность» = тексты, названия, арт, бренд |
| **PHB / XGE / MM…** | Конкретные официальные книги D&D |
| **SRD** | Бесплатный «открытый кусок» правил, который Wizards разрешила использовать почти свободно (с указанием авторства) |
| **CC-BY** | Лицензия SRD: можно использовать, даже коммерчески, но надо написать «взято из SRD» |
| **Fan Content Policy** | Правила Wizards для фанатов: можно делать неофициальные вещи с их миром, но **бесплатно** для людей; продавать сам фан-контент нельзя |
| **community_ref** | Наш ярлык: «официальная книга вне SRD, лежит у нас как бесплатный справочник» |
| **BYO / attestation** | «Принеси своё» / «поставь галочку, что книга у тебя есть» — усиление потом, не замена каталога |
| **ttg / dnd.su** | Популярные русские онлайн-справочники; из них у нас много данных попало в каталог |
| **LSS** | Long Story Short — главный конкурент-лист в СНГ |
| **Paywall** | «Плати, иначе не откроем» |
| **Takedown** | «Пришла жалоба → сняли карточку / текст» |
| **SoT (source of truth)** | «Откуда считаем правдой». Сейчас в аудитах часто SoT = ttg — это и есть риск Б |
| **Провенанс / provenance** | История «откуда взялась строка в базе» |
| **Щит** | Конкретная защитная мера. Не магия, а правило + действие |

# Часть IV. Шесть щитов — подробно, как для новичка

Щиты нужны **все вместе**. Один красивый дисклеймер без остального — как замок на открытой двери.

---

## Щит 1. «Деньги не за книги»

### Зачем

Самый простой и сильный сигнал для любой претензии:  
«Мы не торгуем вашим контентом.»

### Как это выглядит в жизни

Можно когда-нибудь брать деньги за:

- больше персонажей в облаке;
- удобный стол / лобби / шаринг;
- PDF «в один клик»;
- приоритетную поддержку.

Нельзя брать деньги за:

- «открой PHB»;
- «разблокируй всех монстров»;
- «подписка на полный справочник».

### Микродействия

1. Записать в оферту одной фразой: *справочник бесплатен навсегда*.
2. В будущем прайсе не заводить тарифа «Контент / Книги».
3. В коде позже: проверка, что доступ к каталогу не зависит от подписки.

### Как понять, что щит стоит

Человек без аккаунта или на бесплатном тарифе **видит справочник**.  
Платный тариф даёт **удобство инструмента**, а не «больше книг».

---

## Щит 2. «Мы не зеркало ttg / dnd.su»

### Зачем

Даже если Wizards далеко, **русские площадки** могут сказать:  
«Вы выкачали нашу базу.»

У нас в рабочих документах буквально написано, что источник правды для аудитов — ttg/dnd.su.  
Для продукта это опасно как признание.

### Важная развилка (чтобы не перепутать)

| Оставляем | Меняем |
| --- | --- |
| Что игрок видит: эльф, фаербол, бехолдер — **да, охват тот же** | Откуда формально «взято» и как хранится — **не как выгрузка ttg** |

То есть: **не выкидываем монстров**. Выкидываем привычку «парсить ttg как истину».

### Микродействия

1. Больше не запускать скрипты, которые качают API ttg / страницы dnd.su в прод.
2. В документах аудита заменить формулировку SoT:  
   было «источник правды — ttg» → станет «источник правды — официальные книги + наша структура; ttg/dnd.su только исторически помогали сверить список».
3. Убрать из **публичного** API/UI ссылки вида «карточка = страница dnd.su» (внутри для себя можно временно держать пометку «legacy»).
4. Держать свою структуру карточек и свой интерфейс (это у creed20 уже своё — не копировать LSS).

### Как понять, что щит стоит

- В рекламе нет «мы клон dnd.su».
- В коде нет живого парсера конкурента.
- Если спросят «откуда база?» — ответ: «собрали под стол из официальных материалов / своя компиляция», а не «выгрузили ttg».

---

## Щит 3. «Как именно лежит текст»

### Зачем

Претензия сильнее, когда у вас лежит **длинный дословный текст книги** «один в один».  
Слабее (не ноль!), когда у вас:

- числа и механика для игры (КД 16, скорость 30, 2к6 урона);
- короткие свои формулировки черт;
- без официальных картинок Wizards.

### На пальцах

Есть разница между:

- переписать шпаргалку своими словами под калькулятор;  
- и выложить главу учебника целиком.

Мы целимся в шпаргалку для жестов creed20, не в электронную книгу.

### Микродействия (можно волнами, не всё сразу)

1. Для каждой карточки понять: есть ли **длинное описание**.
2. Длинные описания постепенно переписывать своим коротким RU (смысл тот же для игры, слова свои).
3. Никогда не класть официальный арт с обложек/бестиария WotC.
4. Имена (Fireball, Бехолдер) оставляем — иначе стол мёртв; рядом дисклеймер «неофициально».

### Как понять, что щит стоит

Выборочная карточка: нет простыни «как из книги слово в слово», есть playable-поля + короткий свой текст.

---

## Щит 4. «Бумажки и честные таблички»

### Зачем

Взрослый продукт отвечает на вопрос «вы кто и на каком основании».  
Пустая страница без /legal выглядит как «серый сайт».  
Страница с правилами + email для жалоб выглядит как «готовы разбирать».

### Что должно появиться на сайте

1. **`/legal` (или «Правовая информация»)**  
   - кусок правил из SRD используем по CC-BY (с обязательной фразой-атрибуцией);  
   - остальной справочник — неофициальный community / fan-style, не одобрен Wizards;  
   - справочник бесплатный;  
   - платное = сервис creed20.
2. **Email для жалоб** («нашли нарушение — напишите, разберём»).
3. **Правила пользовательского контента** (если игрок сам что-то заливает — ответственность на нём).
4. **Политика персональных данных** (у вас серверы в РФ — это отдельно про 152-ФЗ, не про книги).

### Микродействия

1. Набросать текст `/legal` простым языком (черновик можно без юриста, финал — сверить).
2. Завести mailbox вроде `legal@creed20.app`.
3. Описать внутри команды: пришло письмо → кто смотрит → срок ответа → снять карточку если надо.

### Как понять, что щит стоит

Любой человек за 30 секунд находит на сайте: кто вы, что бесплатно, что платно, куда писать жалобу.

## Щит 5. «Запасной парашют» (не сейчас обязательно)

### Зачем

Если когда-нибудь давления мало от щитов 1–4, можно ужесточить **доступ к длинным текстам**, не убивая охват механики.

Примеры парашюта:

- галочка «у меня есть книга X» открывает полный prose;
- или тяжёлые тексты ставятся файлом с компьютера пользователя.

### Важно

Это **не** «выкинуть справочник».  
Это «ещё один слой двери».  
Сейчас фаза 1 = щиты 1–4. Щит 5 — потом, если понадобится.

## Щит 6. «Как ведём себя снаружи»

### Зачем

Меньше шума = меньше поводов.

### Микродействия

1. В рекламе говорить: «удобный стол и лист», не «полный пиратский PHB».
2. Не ставить логотипы D&D на иконку/шапку.
3. Домен и бренд — **creed20**.
4. Не провоцировать LSS копированием их экранов и «языка формул».

## B0. Инвентаризация («что у нас лежит»)

### Зачем простыми словами

Прежде чем защищать дом, нужно знать, какие комнаты есть.  
B0 — это **опись склада**, не уборка на свалку.

Мы **не** решаем «удалить PHB».  
Мы решаем: пометить каждую запись ярлыком.

### Какие ярлыки

| Ярлык | Значение |
| --- | --- |
| `srd` | Можно почти свободно (открытый кусок от Wizards) |
| `community_ref` | Официальная книга вне SRD — **оставляем, бесплатно** |
| `user_import` | Принёс пользователь |
| `homebrew` | Своя выдумка |

Плюс флажки:

- длинный текст есть / нет;
- след ttg/dnd.su есть / нет.

### Микродействия B0

1. Взять списки: расы, заклинания, бестиарий, черты, снаряжение.
2. Для каждого (или пачками по книге) проставить ярлык.
3. Посчитать: сколько `community_ref` (будет много — это нормально).
4. Составить список «где ещё торчат ссылки/парсеры ttg».
5. Зафиксировать результат в `B0_CATALOG_INVENTORY.md` (сводка уже начата).

### Готово, когда

- нет записей «непонятно откуда»;
- есть цифры по слоям;
- есть список работ для щита 2.

### Уже известно по факту (чтобы не пугаться цифр)

На рабочей линии примерно:

- бестиарий ~2380;
- заклинания ~527 (часть из них SRD, часть нет);
- расы ~118 в спеках;
- черты ~100+.

Всё это **кандидат в `community_ref`**, не в мусорку.

### Зачем

Нет живого зеркала; происхождение объяснимо без слова «скрапнули ttg».

## B3. Монетизация («когда и за что брать деньги»)

### Зачем

Чтобы не сломать щит 1 в момент жадности.

### Простыми правилами

1. Сначала продукт в бете без обязательной оплаты.
2. Потом деньги за удобство.
3. Никогда — за объём справочника.

### Микродействия B3

1. Выписать 5 платных идей (облако, лимиты, PDF, приоритет…).
2. Выписать запретный список («полный PHB за 299₽» — в запретный).
3. Решить: донаты/Boosty на старте или сразу подписка на сервис.
4. Включить оплату только после B1 (бумажки) и публичной беты.

### Готово, когда

Есть прайс-черновик, где ни одна строка не продаёт «книгу».

## B5. PR («как рассказываем людям»)

### Зачем

Привести игроков без юридических грабель в постах.

### Микродействия B5

1. Список каналов (Telegram/Discord/VK НРИ, мастерские).
2. Тон: ранняя бета, просим фидбек.
3. Что говорим: клик, стол, простота.
4. Что не говорим: «у нас весь пиратский PHB», «мы лучше LSS формулами», «официально от Wizards».
5. Один закреп с дисклеймером + ссылка на `/legal`.

### Готово, когда

Есть черновик анонса на 1500 знаков, который не ломает щиты.

# Часть VI. Один сквозной пример

Возьмём карточку заклинания «Аура живучести» (у нас она уже есть, с длинным RU и ссылкой на dnd.su).

| Сейчас | После щитов |
| --- | --- |
| Лежит в базе | Тоже лежит |
| Длинный текст похож на справочник | Короткий свой RU + механика для каста |

# Часть IX. Короткие ответы на частые страхи

**«Нас сразу засудит Wizards?»**  
Нельзя обещать „нет“. Можно сделать так, чтобы вы не выглядели магазином их книг, а выглядели бесплатным community-справочником + своим инструментом. Это сильно снижает типичный мотив претензии.

**«Значит можно всё копировать как есть?»**  
Нет. Охват — да. Зеркало ttg + дословные простыни + продажа доступа — нет.

**«А LSS же урезал спеллы?»**  
У них более «чистый коммерческий» путь. У вас путь другой: полный справочник, но **бесплатный**, деньги за creed20-жесты. Оба пути существуют; вы выбрали второй.

**«РФ-сервер спасает?»**  
От закона про персональные данные — помогает.  
От авторских прав на книги — **не индульгенция**.

**«Что самое срочное?»**  
Щит 1 (не продавать книги) + щит 2 (не быть зеркалом ttg) + щит 4 (`/legal`).  
Охват каталога при этом не трогаем.
