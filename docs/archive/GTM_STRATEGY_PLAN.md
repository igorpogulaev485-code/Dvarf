## 0. Принцип

Продукт — **инструмент листа и стола** (creed20: d20 → история), не энциклопедия книг.  
Данные правил и тексты книг ≠ точка монетизации.  
Монетизация (когда включим) — **удобство жестов** (наполнение листа, облако, шаринг, лимиты, интеграции), в духе «до приключения — клик».

Российские серверы решают **152-ФЗ и операционку**, но **не** дают лицензии на IP Wizards of the Coast.

## 1. Три режима (карта «нельзя → можно»)

| Режим | Можно | Нельзя | Как превратить в можно |
| --- | --- | --- | --- |
| **A. SRD + CC-BY-4.0** | Коммерция инструмента и SRD-слоя | Выдавать *только* SRD как весь продукт | SRD = нижний слой; поверх — community_ref |
| **B. Fan Content / community reference** | Держать официальные книги в продукте **бесплатно**; донаты/реклама; $ за сервис | Продавать доступ к книгам / paywall на каталог | **Наш основной режим для полных справочников** |
| **C. Зеркало ttg/dnd.su** | Быстро набрать охват | Претензия РФ-площадок + «плагиат базы» | **Запрещён как SoT.** Охват сохраняем, происхождение рвём (щит 2) |

### Default-рекомендация (после решения «каталоги оставляем»)

**B (community_ref бесплатно) + A (SRD внизу) + $ только за инструмент.**  
BYO / attestation — щит фазы 2, не условие существования каталога.  
Подробный стек: [`KEEP_CATALOGS_PLAYBOOK.md`](KEEP_CATALOGS_PLAYBOOK.md).

Ключевые опоры:

- [Fan Content Policy (WotC)](https://company.wizards.com/en/legal/fancontentpolicy)
- [SRD / Creator FAQ (D&D Beyond)](https://www.dndbeyond.com/creator-faq) — Basic Rules **≠** SRD
- Практика LSS: встроенное ≈ SRD; остальное через пользовательский Гримуар; [лицензия](https://longstoryshort.app/doc/misc/license/)

## 2. Прецеденты: что брать / не брать

### LSS — главный конкурент СНГ + юридический эталон

- **Брать (legal):** архитектуру «данные ≠ продукт», честность про SRD, UGC/Гримуар для недостающего.
- **Брать (product, выборочно):** только creed20-жесты без которых нет истории (бросок→лента, авто-ASI, импорт) — см. конкурентный canvas §5.
- **Не брать:** UI, тексты, датасеты, ToS; **formula engine и сверхнастройки** (осознанный отказ, iPhone≠Android).

### D&D Beyond — правообладатель

- **Брать:** идею «контент принадлежит владельцу аккаунта» (у нас — только его импорт).
- **Не брать:** парсинг/зеркалирование Beyond; маркетинг «как Beyond, но бесплатно».

### dnd.su / TTG — справочники сообщества

- **Брать:** понимание аудитории и языка РФ-коммьюнити.
- **Не брать:** парсинг HTML/БД, дословные карточки, конкуренцию как «ещё один справочник».
- Претензии «плагиат» от РФ-компаний чаще всего про **копирование кода/структуры/базы**, а не про «ещё один лист». Лечится: свой код, свои UX-тексты, свои данные из SRD + BYO.

## 4. Содержимое блоков (черновик для следующих итераций)

### B0 — Инвентаризация (без вырезания)

**Задача:** матрица `kind × source_book × content_layer × provenance` (+ флаг long_prose / external_ref).

**Критерий готовности:**

- 0 строк «неизвестно»;
- посчитан объём `community_ref` (большой — ожидаемо и ок);
- список следов ttg/dnd.su для щита 2.

**Факт сейчас:** на tip — полные волны рас/бестиария/заклинаний с SoT ttg/dnd.su. B0 классифицирует, не удаляет.

### B1 — Юридический каркас

- `/legal`: SRD CC-BY + community_ref / Fan Content дисклеймер.
- Жёстко в оферте: **каталог бесплатен**; $ = сервис creed20.
- Без логотипов D&D; бренд creed20.
- UGC + takedown email.
- РФ-хостинг ≠ лицензия на книги.

### B2 — dnd.su / TTG / LSS

**Разрешённые источники вшитого контента:** официальный SRD + собственные UX-формулировки + то, что пользователь явно импортировал.

**Запрет:** парсинг справочников; копирование структуры карточек/кода LSS.

**Коммуникация:** «совместимы с правилами 5e через SRD», не «полный перевод PHB / все книги».

### B3 — Монетизация

**Гипотеза по умолчанию:**

- справочные SRD-данные — бесплатны навсегда;
- деньги — за инструмент (автозаполнение листа, облако, шаринг, PDF, лимиты персонажей, интеграции).

**Когда деньги:** только после публичной беты с чистым B0/B1.  
До этого — закрытая поддержка/донаты **без** paywall на IP.

Альтернатива (если остаёмся в Fan Content): ядро всегда бесплатно; $ только за сервисные лимиты, не за «доступ к книгам».

### B4 — Позиционирование

**Уже зафиксировано** (`PRODUCT_PHILOSOPHY.md` + конкурентный canvas). Задача B4 — не писать заново, а:

1. Свести бренд-ось (creed20 / клик / d20→история) с legal-осью (SRD+BYO, не энциклопедия).
2. Зафиксировать однострочник для PR: миссия + слоган + «неофициально / SRD».
3. Moat из canvas держать: Play Desk режимы, бестиарий+бой, сеттинг↔стол; **не** formula engine.

Отстройки (канон):

- vs **LSS** — iPhone vs Android: удобство жестов, не число рычагов;
- vs **Beyond** — локальность, стол/сеттинг, без paywall на книги;
- vs **dnd.su/TTG** — мы не справочник; справочник у нас служит жесту, не наоборот;
- vs **Kanka** — у нас игровой стол + лист, не только вики мира.

### B5 — PR

Каналы: Discord / VK / Telegram НРИ, мастерские, дружественные мастера.  
Голос: creed20 — «до приключения — клик», каждый d20 пишет историю.  
Тон: ранняя бета, фидбек, честно про SRD-границы.  
Не обещать «все расы из всех книг из коробки».  
Не сравнивать публично «мы лучше LSS по формулам» — это чужое поле.

### B6 — Домен и РФ

- Домен: **creed20.app** (принято; проверить владение/DNS/почту).
- Политика ПДн, оферта, cookies — **до** сбора email/аккаунтов.
- Timeweb VPS в РФ — плюс для 152-ФЗ.
- В бренде/мета-тегах: creed20; в репо можно оставаться Dvarf.

### B7 — Точка выхода (Go/No-Go)

1. B0 чист.  
2. `/legal` + атрибуция.  
3. BYO-путь для не-SRD работает.  
4. Маркетинг без обещаний полного PHB.  
5. Закрытая бета с мастерами пройдена.

Порядок: **закрытая бета → публичная бета/ранний доступ → деньги**.
