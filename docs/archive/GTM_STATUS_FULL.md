### Онбординг и стратегия (зачем это важно)

Онбординг **не** юр.слайс и **не** энциклопедия. Это прямой moat «iPhone»: маршрут новичка до жеста, без PHB внутри тура.

| Ось | Влияние |
| --- | --- |
| **Миссия** («D&D простым») | ✅ Закрывает фидбек «круто, но ничего не понятно» |
| **vs LSS** | LSS ≈ рычаги/формулы для тех, кто уже знает; КриD20 ведёт абсолютного новичка жестами + пояснениями на касании |
| **vs Beyond** | Beyond продаёт книги; мы учим *инструмент*, каталог бесплатен |
| **vs dnd.su/ttg** | Они справочник; мы не конкурируем туром по правилам — только продукт + короткие термины |
| **B4 позиционирование** | Усиливает «до приключения — клик»; PR-однострочник можно опираться на welcome |
| **B3 монетизация** | Сильнее история «$ за удобство понимания/жестов», не за текст книг |
| **B5 / B7** | Закрытая бета с новичками реалистичнее; всё ещё нужны legal-пакет и честные обещания |
| **Щиты 1–2 / B2** | Не ломает: не ссылаемся на ttg/dnd.su, не учим «как на справочнике» |

**Не смешивать** с `GuidedWizard` / create-pipeline: те про *правила выборов* (expertise, ASI…); O0+O1 — про *понимание продукта и листа*.

### 4.1 Персональные данные (152-ФЗ) — режим без юрлица + Boosty

> Не юр.заключение.  
> **Решение Игоря (2026-10-20):** ООО/ИП **не будет**; деньги позже — **Boosty** (поддержка автора / ранний доступ к инструменту), не свой эквайринг и не paywall каталога.  
> Оператором ПДн всё равно являемся как **физлицо**: регистрация / OAuth / email = обработка (ст. 3). Отсутствие юрлица **не** снимает 152-ФЗ.

**Что собираем:** email, OAuth (Яндекс, VK), сессии/cookies, IP в логах, кабинет и листы, письма на info@. Спецкатегории / биометрию не берём.  
**Платежи:** карта и чеки — у **Boosty**; в политике: «поддержка через Boosty; платёжные данные у платформы».

#### Делаем / не делаем

| Делаем | Не делаем |
| --- | --- |
| Политика ПДн от **ФИО** + info@ | Приказы ООО, печати, «оферта юрлица» |
| Уведомление РКН как **физлицо** (Госуслуги / бумага / УКЭП физлица) | Штатный DPO, банковский УЗ |
| Чекбокс согласия + удаление аккаунта | Своя касса / эквайринг |
| Хостинг и бэкапы в РФ | Google OAuth без контура трансгранички |
| На Boosty: поддержка / ранний доступ к **инструменту** | Paywall на справочники |

#### Чеклист (облегчённый)

| # | Требование | Статус |
| --- | --- | --- |
| 1 | Уведомление РКН от физлица (`pd.rkn.gov.ru`) | ⏳ |
| 2 | ПДн + бэкапы в РФ (Timeweb) | 🟡 сервер ✅ · бэкапы проверить |
| 3 | Политика ПДн в `/legal` (оператор = ФИО; Boosty отдельно) | ⏳ |
| 4 | Согласие на регистрации / OAuth | ⏳ |
| 5 | Без сторонней аналитики (только сессия) | 🟡 |
| 6 | Удалить аккаунт / отзыв (UI или info@) | 🟡 контакт ✅ · UI ⏳ |
| 7 | Ответственный = ты же (физлицо) | ⏳ в политике и уведомлении |
| 8 | Не плодить лишних SaaS с ПДн; оферты Timeweb/Яндекс/VK/Boosty | 🟡 |
| 9 | Google/TG OAuth — не включать без уведомления о трансграничке | ✅ сейчас РФ · ⏸ Google |
| 10 | HTTPS + здравый смысл при утечке | 🟡 HTTPS ✅ |

**Минимум до открытой беты / PR:** **1, 3, 4, 6**.  
**Когда появится Boosty:** строка в `/legal` + на странице Boosty: платят за инструмент/поддержку, каталог бесплатен (щит 1).

Код: политика + чекбокс + delete-account. Бумаги РКН — Игорь как физлицо.
