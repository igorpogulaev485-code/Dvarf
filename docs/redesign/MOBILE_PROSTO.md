## Три волны

### P0 — чтобы можно было играть с телефона
- Внизу вкладки: Бой · Исследование · Общение · Напарники · Способности (**без «ЕЩЁ»**)  
- На экране **одна** зона, не всё сразу.  
- Хиты, отдых, состояния, монеты — на виду.  
- Характеристики — **отдельная страница** из шапки (не вкладка).  
- **После desk-докачек 14.10:** прыжок, щит у КД, разборка бафов, рейл как в LSS, черты в «Основном» — тоже на телефоне.

### P1 — чтобы было быстро
- Каст (Бой/Книга уже в коде), рюкзак, общение, умения, напарники.  
- История бросков / преим. из безрассудной.  
- Создание персонажа с понятными шагами.  
- Лобби: крупный код, QR по желанию.

### P2 — полировка
- Лёгкие анимации, мелочи шапки, кабинет.

## Чего не делаем

- Не перерисовываем десктопный кит.  
- Не меняем правила хитов и заклинаний.  
- Не пишем отдельное iOS/Android-приложение (пока это мобильный сайт).  
- **Не деплоим mobile**, пока ветка не содержит live prod tip (иначе затрём сегодняшний стол).
