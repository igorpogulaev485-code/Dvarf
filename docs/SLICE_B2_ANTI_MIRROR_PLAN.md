## Цель (простыми словами)

Справочники **остаются** в КриD20 и **бесплатны**.  
Меняем не охват, а **происхождение**: продукт больше не выглядит и не ведёт себя как «зеркало ttg / dnd.su».

Сейчас в доках и скриптах до сих пор написано «источник правды = ttg». В данных есть `external_ref` на dnd.su. Есть скрипты `fetch_*`, которые ходят в API ttg / HTML dnd.su. Это и есть риск B из playbook.
