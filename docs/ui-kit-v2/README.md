## Зачем новый кит, если Листва уже есть?

Можно захотеть новый кит, если:

- хочется **другое ощущение бренда** (не «оливковый пергамент»);
- Листва слишком близка к типичному «AI fantasy UI» (кремовый фон + тёплый акцент);
- нужны более **игровые** состояния (бой / исследование) без смены всей логики.

Это нормально. Но смена кита = **большое решение**: все экраны, темы кабинета, доски, агенты.

Пока нет твоего явного «берём Atlas / Forge / Scriptorium» — код живёт на Листве.

## Три направления (выбери одно)

| | A · **Atlas** (рекомендуем) | B · Forge | C · Scriptorium |
|--|----------------------------|-----------|-----------------|
| Ощущение | Стол с **картой похода** | Кузница, искра, камень | Архив, чернильница |
| Фон | Прохладный туман `#F3F5F4` | Тёплый камень `#F1EFEB` | Холодная бумага `#F5F7FA` |
| Accent | Мох `#2F6A4F` | Ember `#C45C26` | Navy `#2C4A6E` |
| Чем не является | Не кремовый пергамент | Не «терракота на креме» целиком* | Не фиолетовый SaaS |
| Риск | Близко к зелени Листвы — но холоднее | Accent горячий, осторожно с СИЛ/danger | Может казаться «офиснее» |
| Доска | [`boards/dir-a-atlas.svg`](boards/dir-a-atlas.svg) | [`boards/dir-b-forge.svg`](boards/dir-b-forge.svg) | [`boards/dir-c-scriptorium.svg`](boards/dir-c-scriptorium.svg) |

\*Forge специально сдвинут в камень/искру, чтобы не копировать связку «cream + terracotta + serif».

**Рекомендация команды (черновик):** **Atlas** — светлый, игровой, отличается от Листвы, хорошо ложится на лист/лобби/create.

## Что входит в UI Kit (чеклист «готово»)

- [ ] Метафора / ощущение продукта (1 фраза)
- [ ] Цветовые токены (нейтрали + accent + danger + semantic)
- [ ] Цвета характеристик (не зависят от темы)
- [ ] Типографика (display + UI + numeric)
- [ ] Радиусы, отступы, тени/elevation
- [ ] Атомы и их состояния (button, chip, field…)
- [ ] Паттерны (panel, desk header, catalog card, empty…)
- [ ] Иконки (правило: до кода блока)
- [ ] Motion (3–5 осмысленных)
- [ ] Do / Don’t
- [ ] Миграция с Листвы (что переименовать, что выкинуть)
- [ ] Ok Игоря → потом код

Atlas закрывает это в [`ATLAS.md`](ATLAS.md).
