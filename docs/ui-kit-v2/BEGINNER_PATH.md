# Новый UI Kit Dvarf — путь для новичка (делаем вместе)

Цель: **новый UI Kit**, грамотно и по шагам.  
Не цель: сразу переписать весь прод.

Сейчас на проде — **Листва** (`docs/ui-kit-current/`).  
Новый кит живёт как черновик в `docs/ui-kit-v2/`, пока ты / разработчик не скажете «берём».

---

## Золотые правила (запомни 5 штук)

1. **Сначала ощущение, потом цвета** — иначе кит развалится.  
2. **Сначала макеты в Figma, потом код** — иначе на проде каша.  
3. **Один accent** для кнопок; danger отдельно; характеристики своих цветов.  
4. **Проверяй на 3 экранах:** логин/список · лист · лобби.  
5. **Не ломай логику игры** ради красоты (хиты, каст, сейв).
