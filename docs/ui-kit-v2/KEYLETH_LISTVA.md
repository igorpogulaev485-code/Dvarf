# Keyleth → тема «Листва» — разбор и варианты для Dvarf

**Миссия продукта:** *«Дварф — как до приключения один клик.»*  
**База темы:** светлая **Листва**, вдохновлённая друидом **Keyleth (Vox Machina / Critical Role)**.  
**Важно про IP:** мы берём **цвет, настроение, метафоры**. Не копируем лицо, костюм, логотипы и официальный арт Critical Role. Рефы Pinterest/Google — moodboard, не исходники для вставки в продукт.

---

## 1. Кто такая Keyleth (кратко и по делу)

| | |
|--|--|
| Кто | Полуэльфийка-друид, Air Ashari, позже **Voice of the Tempest** |
| Игрок | Marisha Ray (Critical Role C1; также TLoVM) |
| Дуга | Застенчивая ученица → лидер, что защищает природу и людей |
| Силы | Стихии (особенно воздух), Wild Shape, погода, связь с природой |
| Символы | Рогатый circlet (наследство матери), посох, листья, плащ бури |

### Характер (для UX, не для фанфика)

1. **Искренность** — «сердце нараспашку», без циничного SaaS-глянца.  
2. **Неловкость → сила** — сначала мягко и просто, внутри мощно (как Minxie / elemental).  
3. **Моральный компас** — в интерфейсе: ясные «правильные» CTA, честные stub’ы, без тёмных паттернов.  
4. **Забота о мире** — спокойный фон, «живой» зелёный, воздух/свет, не кислотный неон.  
5. **Путь Aramenté** — рост по шагам (как create pipeline): не всё сразу, но к цели.

### Внешность → палитра (что можно «считать»)

| Элемент персонажа | Цвет / ощущение | Роль в UI |
|-------------------|-----------------|-----------|
| Рыжие волосы | медь / имбирь `#C45A2C`…`#B85C38` | тёплый акцент (не primary button) |
| Зелёные глаза | изумруд / листва | **главный accent** |
| Светлая кожа + веснушки | тёплый свет, мягкая текстура | фон / микро-шум (очень тонко) |
| Зелёная мантия | sage / moss / forest | panel titles, tabs on |
| Коричневые сапоги / дерево посоха | bark `#6B5344` | вторичный нейтраль, бордеры «теплее» |
| Золото украшений | soft gold `#B08A3E` | редкий shine (XP, успех) |
| Осенние листья (поздний образ) | охра / терракота листьев | hover / autumn mode / warn soft |
| Воздух Ashari / Zephrah | mist, небо | bg gradient «воздух горы» |
| Mantle of the Tempest | тёмно-зелёная кожа → листья | deep green для sticky / desk chrome |

## 2. Связь с миссией «один клик до приключения»

Keyleth перед Aramenté = **сборы в путь**, не сам бой дракона.

| Идея Keyleth | В Dvarf |
|--------------|---------|
| Подготовка без страха | Пустые состояния мягкие + одна ясная кнопка |
| Природа как дом | Пергамент/туман + листва, не «офисный белый» |
| Рост по шагам | Create / level-up как путь, не стена настроек |
| Сила внутри тихого | Primary CTA спокойный зелёный; опасное — отдельно danger |
| Команда (Vox Machina) | Лобби = круг друзей у костра, не «админка серверов» |

**Фраза темы Листва (черновик):**  
*«Светлая поляна у подножия горы — собрал героя и вышел в путь.»*

## 3. Что уже есть в проде (Листва) vs куда тянем

| Токен сейчас | Hex | Keyleth-сдвиг |
|--------------|-----|----------------|
| `--accent` Листва | `#5a6b3d` | чуть живее / «глаз друида» или глубже «мантия» |
| `--accent-soft` | `#e5ecd4` | добавить воздуха (менее желтоватый) |
| `--panel` | `#fbf7ec` | сохранить тепло ИЛИ чуть холоднее mist |
| Ability МДР | = Листва | ок: мудрость = друид |

Риск: не скатиться в клише «крем + терракота + serif».  
Рыжий Keyleth используем как **вторичный** акцент (волосы), не как весь бренд.

## 4. Три варианта темы «Листва × Keyleth»

Смотри превью: canvas + SVG в `boards/keyleth-*.svg`.

### Вариант A — **Zephrah Spring** (рекомендую для v1)

«Утро на горной поляне, до похода.»

| Token | Hex | Зачем |
|-------|-----|--------|
| `--bg` | `#F4F7F2` | воздух, не жирный пергамент |
| `--panel` | `#FBFCFA` | чистая поверхность |
| `--ink` | `#1E2A22` | читаемый «лес» |
| `--muted` | `#5E6B60` | мягко |
| `--line` | `#D5DDD4` | ветка/лист тонко |
| `--accent` | `#3F6B45` | глаза / молодая листва |
| `--accent-soft` | `#E2EEDF` | soft CTA |
| `--ginger` | `#C45A2C` | волосы: chip «выбрано», XP spark |
| `--bark` | `#6B5344` | secondary outline |
| `--gold` | `#B08A3E` | редкий успех |
| `--danger` | `#B42318` | без изменений по смыслу |

**Шрифты:** Fraunces или Source Serif 4 (display) + IBM Plex Sans (UI).  
**Мотивы:** лёгкий leaf-shape у active tab; без рогов на каждой кнопке.

**UX-ощущение:** свежо, дружелюбно, «один клик».

## 5. Компоненты «в духе Keyleth» (без копирования арта)

| Компонент | Как обыграть |
|-----------|----------------|
| Primary button | accent зелень, **tactile pill** (raised/pressed), не flat SaaS |
| Mode «Бой» | мягкий soft → solid; внутри силы, снаружи спокойствие |
| Success / rest | leaf / soft gold, не кислотный green |
| Create steps | «Aramenté»: progress как тропа (dots / path), не агрессивный wizard |
| Lobby | «круг у костра» — аватары рядом, код крупно как «знак сбора» |
| Empty state | тёплый one-liner + одна soft CTA («Собрать героя») |
| Danger | никогда зелёным; только danger-red |
| Иконки | лист, ветер, посох-линия; **не** копировать circlet CR как логотип |

## 6. Do / Don’t для этой темы

**Do**
- Зелень + воздух + редкий рыжий spark.  
- Спокойные поверхности, крупные цифры HP.  
- Миссия «один клик» = один primary на экран.  

**Don’t**
- Весь UI в рыжем «под волосы».  
- Фиолетовый glow / neon-glass (AI-клише). Soft frosted glass для оболочек — ок, см. [`FOUNDATIONS_GLASS_TACTILE.md`](FOUNDATIONS_GLASS_TACTILE.md).  
- Стекло на боевых цифрах и плотных таблицах.  
- Вставлять фан-арт Keyleth в продукт.  
- Писать «официальная тема Critical Role».  
- Ломать rail A identity под «всё зелёное».

- `Беру C Air Ashari`

1. страницу Foundations в спеке (кнопки/chips/HP),

3. короткий пакет для разработчика.
