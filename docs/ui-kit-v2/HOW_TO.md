# Как придумать UI Kit — шпаргалка для стажёра

UI Kit = **правила конструктора**: из каких цветов, шрифтов и кнопок собран весь продукт.  
Не «красивая картинка одного экрана», а **система**, чтобы лист, лобби и создание выглядели одной семьёй.

---

## 7 шагов (делай по порядку)

### 1) Одна фраза про ощущение
Напиши: «Dvarf должен ощущаться как ___».

Примеры:
- «стол с картой перед игрой» → Atlas  
- «металл и искра» → Forge  
- «архив заклинаний» → Scriptorium  

Если фразы нет — кит развалится: каждый экран будет «из другого мультфильма».

### 2) Зафиксируй ограничения
У нас уже есть:
- светлая тема по умолчанию (не уходим сразу в тёмный «игровой неон»);
- desktop + телефон;
- много цифр (HP, слоты, КД);
- долгие списки (заклинания, рюкзак, расы);
- нельзя ломать логику игры ради красоты.

### 3) Выбери нейтрали, потом accent
Сначала фон / текст / линии (на них 80% экрана).  
Потом **один** фирменный accent для кнопок и активных вкладок.  
Отдельно — danger (удалить, опасная зона): он **никогда** не равен accent.

### 4) Характеристики — свои цвета
СИЛ / ЛОВ / … должны отличаться друг от друга и **не перекрашиваться**, когда игрок сменил тему аккаунта.  
Это уже проверено в Листве (rail A) — в новом ките принцип тот же, другие hex.

### 5) Два шрифта максимум
- Display — заголовки, характер.  
- UI — кнопки, списки, формы.  
Цифры лучше tabular (ровные колонки HP/слотов).

Не бери Inter «просто потому что привычно», если нет причины.

### 6) Собери атомы и состояния
Для кнопки сразу рисуй не одну, а пачку:

`default · hover · active · disabled · loading · danger`

То же для chip, field, toast. Иначе в Figma красиво, в продукте — зоопарк.

### 7) Проверь на трёх экранах
Один кит обязан выжить на:
1. шапке листа (много цифр),
2. лобби (код/QR),
3. создании (карточки каталога).

Если на одном экране «вау», а на другом «боль» — кит сырой.

## Частые ошибки новичков

| Ошибка | Почему плохо | Что делать |
|--------|--------------|------------|
| 8 акцентных цветов | Нет иерархии | 1 accent + semantic |
| Всё в карточках с тенью | Шум, не «стол» | Card только для выбора |
| Новый кит = сразу весь код | Прод мигнёт кашей | Сначала доски → ok → волна restyle |
| Скопировать Dribbble dark purple | Не наш бренд, плохо читается днём | Светлая база + свой характер |
| Забыть пустые состояния | Игрок тупит | Empty + кнопка «что делать» |
| Анимация везде | Усталость | 2–3 осмысленных motion |

## Мини-упражнение (15 минут)

1. Выбери направление A/B/C из [`README.md`](README.md).  
2. На бумаге/Figma нарисуй **одну** кнопку primary и **одну** строку атаки.  
3. Спроси себя: «это похоже на мою фразу из шага 1?»  
4. Напиши в чат: «беру X, потому что …».

После этого можно углублять спеку и доски.
