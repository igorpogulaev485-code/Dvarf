# TOUR-01 — тур по листу + карточки сцен

Короткий онбординг листа без трогания UI-кита принятых блоков и мастера создания.

- **5 шагов тура:** шапка → хот-панель → сцены → ход в «Бою» → справка.
- Запуск только после создания («Как читать лист») и из справки «Показать подсказки снова».
- Карточки «что здесь» при первом входе в Исследование / Общение / Способности / Напарники (сегменты новичка и «играл, но тут впервые»).
- Якоря: свёрнутые vitals на 390, hot-bar, turn-actions; тур сам открывает «Бой» перед шагом хода.
