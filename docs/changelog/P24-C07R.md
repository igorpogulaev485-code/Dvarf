# P24-C07R — пересборка текстов бестиария SRD (C07+C08) и 4 подклассов C04

Дата: 2026-11-15.

## Что сделано

- `creatures_srd.json` (235) и `animals_srd.json` (95): traits / actions / bonus / reactions / legendary и колдовство пересобраны со страниц next.dnd.su (редакция 2024), формат как у C13/C14.
- `spell_refs` только из блока «Сотворение заклинаний» (пример: лич — detect-magic, detect-thoughts, invisibility, …; без counterspell/shield из реакции).
- 4 подкласса SRD с заглушками (`cleric__life-domain`, `druid__land`, `paladin__oath-of-devotion`, `warlock__fiend-patron`): умения коротко по next.dnd.su.
- Миграция `p24c07rbest01` → идемпотентный upsert каталога 2024.
- Тест `test_p24_c07r_bestiary_text.py`: нет заглушек во всех `live/*.json`, атаки с бонусом/Сл, пробелы перед пунктуацией.
