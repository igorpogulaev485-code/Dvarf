## Аудит формул vs примеры из ревью (не источник правил)

Сверка с PHB 2024 / принятыми live-карточками. Примеры из длинного списка ревью **не** канон.

### Расхождения с примерами ревью

| Тема | Пример в ревью (ошибочный/смешанный) | Канон 2024 / карточка | Было в коде | Стало |
|---|---|---|---|---|
| Берсерк Frenzy | «число к6 = БМ» | к6 × **бонус Урона ярости** (2/3/4), при ярости + Безрассудной атаке | calc уже `dice_count_from: rage_damage`, но не шёл в бросок стола | + `requires_reckless_attack`; rider в `PlayDeskAttacksCompact` → `extraDamages`; summary live |
| Убийца Assassinate | «преим./крит по surprised» (2014) | преим. к инициативе; в 1-м раунде преим. vs ещё не ходивших; Коварная +ур. плута; **без** авто-крита | `crit_vs_surprised: true` | `crit_vs_surprised: false` + init/round1/SA-extra; чип стола; init advantage на листе |
| Свет Warding Flare | память «ПБ/длинный» | **мод. Мудр** (мин. 1); long; с 6 — short или long | пул уже Wis; summary «ПБ/длинный» | summary исправлен; тесты Wis≠PB |
| Fiend Dark One's Blessing | путаница с «Бездонным»/GOO | подкласс **Исчадие** (`warlock__fiend-patron`), temp HP = Хар + ур. | уже на Fiend + кнопка → temp HP | подтверждено тестом; GOO без blessing |
| Arcane Ward | старая память размера/условий | max = **Инт + 2×ур.**; create/restore Ограждением с ячейкой (+2×круг); до long rest | max верный; create/restore уже на касте | meta `create_on` / `restore_on`; summary; тесты |

### Где значение реально используется (не только JSON)

- **Frenzy** → `resolveAttackRoll.extraDamages` на столе (ярость + reckless + Str).
- **Assassinate** → бонус к инициативе (`PlayDeskTop`); flat +ур. в `damageExpr` при чипе «ещё не ходила».
- **Warding Flare** → пул `warding_flare`, spend на листе (`ClassFeaturesPanel` / `spendFeatureUse`).
- **Dark One's Blessing** → кнопка → `b05FeatureSpend` → temp HP на листе.
- **Arcane Ward** → stock на листе; `createArcaneWard` / `applyAbjurationToWard` при касте Ограждения; поглощение урона `absorbDamageWithArcaneWard`.
- **Champion crit / Draconic AC** → уже в броске атаки и формуле КД (edition-gated).
