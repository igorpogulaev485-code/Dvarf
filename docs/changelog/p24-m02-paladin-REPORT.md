## 4. Удобство 2014 → ветка `rules_edition === '2024'`

- Диалог Возложения рук: 2014 путь без изменений; 2024 — бонусное, яд без болезни, Restoring Touch.
- `ChannelDivinitySpendDialog` / `Paladin2024UseDialog` — трата/возврат канала и капстоунов.
- Карточки кнопок в `ClassFeaturesPanel` только при edition 2024.
- `DivineSmite` / Improved Divine Smite 2014 не переписывались общими числами; 2024 rider читает `radiant_strikes`.
- Create: FS с 2 ур. для паладина; Blessed Warrior; мастерство с 1-го.

## 5. Расхождения и книжные клятвы

- **Книжные клятвы вне пачки:** с next.dnd.su — **Клятва благородных гениев** (`paladin__oath-of-the-noble-genies`, FRHoF); из 2014 в проекте ещё встречаются клятвопреступник, короны, покорения, искупления, смотрителей — **не делались**.
- Опечатка сайта «из вашей книги заклинаний» у паладина — проигнорирована (книги нет).
- «Божественное чувство» не умение 1-го (исправлено замечание M02a).
- Имена по правилу Игоря / **ИТОГОВЫЕ ИМЕНА**: Проведение божественности, Сияющие удары, Восстанавливающее касание, Кара паладина / Божественная кара, Аура опеки, Расширение ауры.
- Было в карточке → поставили: «Колдовство»→«Сотворение заклинаний»; «Мастерство оружия»→«Оружейное мастерство»; «Божественный канал»→«Проведение божественности»; «Отречение врагов»→«Порицание врагов»; «Наложение рук» (RESOURCE_META)→«Возложение рук»; «Святой нимб»→«Священный нимб»; «Воодушевляющий удар»→«Воодушевляющая кара»; «Несравненный атлет»→«Непревзойдённый атлет»; «Блестящая оборона»→«Славная оборона»; «Ангел отмщения»→«Ангел возмездия»; «Клятва возмездия»→«Клятва мести».
- Мультикласс half_up для паладина/следопыта (SRD 5.2.1); тесты M03c обновлены.
- Spell lists клятв Glory/Ancients/Vengeance в справочнике были с неверной нарезкой кругов — исправлены по PHB 2024.
