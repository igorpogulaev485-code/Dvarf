# FIX-01: мобильный каст, описание заклинания, окно «Цель атаки»

## Сделано

1. **Китовый Dialog (iPhone Safari)** — высота подложки `100svh` → `100dvh` (без `100lvh`), `viewport-fit=cover`, нижний safe-area на мобилке, тело `touch-action: pan-y` / `overscroll-behavior: contain`, футер с кнопками вне прокрутки; опция `showClose` (крестик).
2. **Описание заклинания** — тап по названию открывает `SpellDetailDialog`; тап по остальной строке раскрывает мету; в мете кнопка «Описание».
3. **Цель атаки** — Escape / фон / крестик = `onDismiss` без броска; галочки → `ToggleChip`; «Источник страха виден» выкл по умолчанию и только если атакующий испуган; «Цель ослеплена» / «Цель невидима»; состояния со стола подставляются при выборе цели; попадание = итог ≥ КД (nat 1 промах, nat 20 крит); урон и снятие хитов только при попадании через `POST /sessions/{id}/combat/sheet-attack` (временные хиты первыми), в ленте имя цели и итог хитов; без цели — хиты не трогаем.
4. **Одна строка хода** — `TurnEconomyCombatActions`: Действие / Бонусное / Реакция раскрывают каталог под строкой; сверху свои умения/заклинания по `kind` и `casting_time` (у паладина в «Действии»: Атака, Заклинание, Божественное чувство, Возложение рук, Божественный канал), затем общие (Поиск, Рывок…), редкие DMG под «ещё»; в бою в той же строке отметки Взаимодействие / Движение. На 390 — перенос/сжатие чипов без обрезки, нормальные отступы у активного. Потраченное — ✓ и приглушение (без зачёркивания); снять отметку — в раскрытом списке. Отдельная строка `TurnEconomyChips` на панели атак убрана (на карточках стола чипы остаются).
5. **ToggleChip is-on** — только solid `--accent` + белый текст (как метамагия MAG-01); soft fill не допускается.
6. **Описание заклинания** — текст/дистанция/шкала урона из бандла `spells-2014` (и API-каталога); урон как у каста (`resolveCastEffectSummary`); уровень заговора — «Заговор».
