## Сделано

1. **Благочестие** — блок только если в кампании включён MOT (`allowed_sources` включает `mot`) **или** у персонажа выбран бог. Иначе панели нет.
2. Убран вступительный абзац (`features-panel__lede`).
3. Фильтры ровно 5: **Все / С ресурсом / Нужен выбор / Пассивные / Свои**. Пустые (0 умений) скрыты. Поиск на месте.
4. Порядок карточек: сверху «нужен выбор» (бейдж китовый `Chip`), дальше в группе умения с ресурсом, потом пассивные.
5. **Тёмное зрение** — одна карточка (дубли из trait cards отфильтрованы, если есть `darkvision` prop).
6. Подпись ресурса монаха — **«ци»** (через `displayResourceLabel`, QI-01 уже был; на карточке умений тоже).
7. **Предок-дракон**: выбор из мастера/`subclass_setups` / `choice.id` (`draconic_ancestry`) больше не показывается как «не выбрано» — bridge при загрузке листа + `getFeatureChoicePick`.
8. **Доправка:** левая панель «Тёмное зрение —» у дварфа без дистанции — **не регрессия ABL** (в `main` у сида Даррака `combat.darkvision=0`, нет `race_grant`). Починена подстановка из расы (`raceDarkvisionFallbackFt` по grant/slug/имени). Стиль левой панели не меняли. Кадры ТЗ пересняты обычным вьюпортом 1440/390.
9. **Доправка `at_use`:** бейдж «нужен выбор» / «не выбрано» только для **постоянных** выборов (стиль боя, предок, ASI, метамагия…). Умения, где вариант берётся **на каждое применение**, помечены `choice.at_use` — без бейджа и без селекта на листе. Снято с:
   - **Техника открытой ладони** (`open_hand_technique` / монах Путь открытой ладони)
   - **Форма зверя** (`form_of_the_beast` / варвар Путь зверя) — оружие на ярость
   - **Расцвет клинка** (`blade_flourish` / бард Коллегия мечей)
   - **Собранный рой** (`gathered_swarm` / следопыт Рой)
   - **Приглушение стихий** (`dampen_elements` / жрец Природы) — тип на реакцию
   - **Элементальный дикий облик** (`elemental_wild_shape` / друид)
   - **Звёздная форма** (`starry_form` / друид Круг звёзд) — созвездие на активацию
   - **Мастер преобразования** (`master_transmuter` / волшебник) — эффект при уничтожении камня
   Оставлены как постоянные: камень преобразующего, тотемы, штормовая аура, предок-дракон, боевые стили, ASI и т.п.
