# CMB-02 — «Кара» и «Действия хода» в сцене «Бой»

Ветка: `cursor/ux-CMB02-smite-turn-6c31` · база `main` · **не мержить** без Игоря.

## Что сделано

### Кара (только при `divine_smite`)

1. Постоянная плашка между «Действиями хода» и оружием **убрана**.
2. У рукопашного оружия и безоружного удара — маленькая кнопка кары (иконка кита + tip).
3. Полоска кругов раскрывается **под строкой** этого оружия: заранее (arm) или после броска атаки (confirm).
4. Кнопки кругов: `N · Xк8` + квадратики остатка ячеек (`ui-resource-pip`). Круги с `max=0` не показываются; пустые — неактивны с tip.
5. Тексты: «Попал? Выбери круг» + «Промах» + «нежить / исчадие» в одной строке.
6. Натуральная **1** → промах для кары: удар закрывается, ячейка не тратится, кара не предлагается.
7. Натуральная **20** → крит автоматически (кости кары удваиваются через существующий `rollDamage`).
8. После применения — чип излучения (`sheet-chip is-on`) под строкой.
9. Учёт хода / API / кости / миграции **не менялись**. «Улучшенная божественная кара» и кары-заклинания не трогались.

### Действия хода

1. Вместо свёрнутого `details` — строка из трёх кнопок **Действие · Бонусное · Реакция**.
2. Состояние хода: свободно / потрачено (**галка + приглушение**, без зачёркивания).
3. Нажатие раскрывает варианты этого вида; сверху личные, ниже общие; DMG — под «ещё»; слепое/дьявольское зрение — info-чипы.
4. Строка `everyTurn` под оружием **убрана** (без дубля): Хитрое действие / Точное прицеливание / второе оружие живут в группах.
5. Пустая группа (напр. бонусное у воина 1) — кнопка неактивна с tip «Нет бонусных действий».
6. У каждого варианта tip (бросок / только отметка).
