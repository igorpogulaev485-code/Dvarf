# SOC-01 — сцена «Общение»

Ветка: `cursor/ux-SOC01-social` · база `main` (`42518bc7`) · **не мержить** без Игоря.

## Что сделано

1. Убран вступительный абзац. Ссылка в «Способности» — маленькая кнопка (`play-desk-compact__link`) **в одной строке** с заголовком «Общение» через `Panel` `titleAside` / `.ui-panel__heading`.
2. Внешность — одна строка взгляда; правка по «Изменить». Текстовая карточка `appearance` влита в этот блок (второй заголовок «Внешность» не рисуется).
3. Заполненные карточки личности — просмотр (заголовок + 2–3 строки), правка по «Изменить».
4. Пустые поля личности — одной строкой «Не заполнено: … · заполнить» (клик по имени или «заполнить» открывает редактор).
5. Фильтры — только непустые категории.
6. На 390 редактор открывается окном `Dialog`, лист не раздувается.
7. Плейсхолдеры «4 фута / 160 фунтов» остаются только в режиме правки и не считаются заполненными.
8. Служебная строка «Ресурсы без блока» в сцене «Общение» **не показывается** (данные в `play.resources` не удалялись). Ресурсы с `onHot` — на хот-панели; привязанные к блоку — в карточке блока («+ Вставка → Ресурс»); классовые пулы — во вкладке «Способности».
9. «Свернуть все / Развернуть все» — только если раскрываемых карточек **больше одной**.
10. На 390: длинная строка «Внешность» обрезается с многоточием внутри карточки (`text-overflow: ellipsis`).
11. На 390: убран белый фон sticky-тулбара у «Добавить блок» (`.text-panel .inventory-panel__toolbar` → transparent).
