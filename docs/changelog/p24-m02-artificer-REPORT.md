## Доправка 1 (после вердикта «доправка»)

1. **Известные схемы** — обязательный выбор в create с 2 ур. (N по таблице: 5→4, 11→6, 20→8). BE валидирует exact N; лист не показывает `(0/N)`.
2. **Панель реплик EFA** — создание по известным схемам до лимита «Магические предметы»; при превышении исчезает старейшая; настройка учитывается. Кадры `*-replicates-panel-*`.
3. **Предмет, хранящий заклинание** — выбор заклинания 1–3 в мастере с 11 и на карточке (диалог). Кадры create-at-11 + levelup 10→11.
4. **Спутники** — открытые панели «Мистическая пушка» / «Стальной защитник» 1440+390 (фикс: `eldritch-cannon` / `steel-defender` больше не сносились revokeFalseSubclassCompanions).
5. **summary_ru артиллериста** — «Магическое огнестрельное» (FE+BE+fixture).
