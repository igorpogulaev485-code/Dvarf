# P24-02 — базовые правила редакции 2024

Дата: 2026-11-15. Ветка `cursor/edition-P24-02-core-rules` (поверх P24-01). **Не открывает** 2024 игрокам. Вливать после PR #448.

## Что сделано

- Истощение 2024 рядом с 2014: −2×уровень к D20 Test, −5 фт×уровень скорости; на 6 смерть; без лестницы 2014.
- Героическое вдохновение: переброс любого кубика после броска; макс. 1; передача союзнику; не преимущество 2014.
- Длинный отдых 2024: все кости хитов, нужен ≥1 хит, пауза 16 ч (хелперы); 2014 «половина костей» не тронут.
- Неожиданность 2024: помеха к инициативе, без раунда L-21. Действия Магия / Изучение / Влияние / Использование; Прятаться Сл 15.
- Тумблеры лобби 2024: те же ключи, подписи под SRD 5.2.1 (зелье / стопка / суровый отдых / доп. черта).
- Состояния: карточки Grappled / Incapacitated / Invisible / Exhaustion 2024; «окровавлен» из хитов.
- `RULES_EDITION_2024_OPEN` по-прежнему выкл.

Лист, лобби, истощение-лестница, вдохновение-преимущество, L-21, тумблеры и отдых 2014 не меняют поведение.
