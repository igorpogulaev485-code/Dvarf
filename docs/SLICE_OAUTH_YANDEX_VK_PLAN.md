# План слайса: OAuth Яндекс ID + VK ID

**Статус:** в плане · **ждём ok** → код → скрины → ok → прод  
**Контур:** план → **твой ok** → код → **скрины** → **твой ok** → прод  
**База после ok:** live tip `cursor/b0-content-layer-6151`  
**Приоритет:** сразу после B0 (размещено в живом порядке плана)

---

## Зачем

На логине кнопки «Войти через Яндекс» / «VK ID» есть, но **вход не работает** (или только частично).  
Нужен рабочий вход с телефона одним тапом — иначе люди упираются в email/пароль.

---

## Что сейчас (факт)

| Провайдер | Код | Секреты на VPS | Поведение |
| --- | --- | --- | --- |
| **Яндекс** | Реальный обмен кода (`yandex.py`) | `YANDEX_*` заданы | Часто ломается из‑за **redirect URI** (ещё http/IP), CORS/APP URL, кабинета OAuth-приложения |
| **VK ID** | **Заглушка** в `exchange_code` | `VK_*` заданы | Старт URL может открыться, обмен кода **не реализован** |

На логине до сих пор текст вроде «VK ID пока заглушка» / «нужны ключи» — уберём, когда реально заработает.

Домен теперь **https://creed20.tech** — callback’и должны быть на HTTPS-домене, не на голом IP.

---

## Цель слайса

1. **Яндекс ID** — полный круг: кнопка → Яндекс → callback → сессия → персонажи.  
2. **VK ID** — убрать заглушку, полный круг (или честно скрыть кнопку, если ключей/приложения не хватает — решение в acceptance).  
3. Redirect URI в `.env` и в кабинетах Яндекс/VK = **https://creed20.tech/...** (точный путь зафиксируем в коде при реализации).  
4. Убрать с логина отладочные фразы про «заглушку / ключи в env».

---

## Что делаем (после ok)

### A. Конфиг / домен

- `YANDEX_REDIRECT_URI` / `VK_REDIRECT_URI` → HTTPS creed20.tech  
- В кабинете [Яндекс OAuth](https://oauth.yandex.ru/) и VK ID — те же URI (это шаг **с твоей стороны** в панелях приложений; дам точные строки в коде/PR)  
- `APP_PUBLIC_URL` / CORS уже смотрят на https — сверим ещё раз

### B. Яндекс

- Прогнать start → callback → `login_with_oauth_profile`  
- Ошибки понятным русским на экране (не «белый экран»)  
- Скрины: до/после входа

### C. VK ID

- Реализовать `exchange_code` (PKCE / токен / профиль — по актуальной схеме VK ID)  
- Те же скрины  
- Если приложение VK не готово: временно **не показывать** кнопку, а не оставлять заглушку-обманку

### D. UI логина

- Убрать developer-note про env/заглушку  
- Кнопки только для реально доступных провайдеров

## Acceptance

1. С телефона: «Войти через Яндекс» → попадаешь в персонажи.  
2. VK ID: либо то же, либо кнопки нет (не заглушка).  
3. Email/пароль по-прежнему работают.  
4. На логине нет текста «заглушка / ключи в env».  
5. Скрины → твой ok → прод.
