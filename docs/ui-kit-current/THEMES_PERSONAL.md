# Темы аккаунта — что есть сейчас + личная тема

## Честный ответ про «тёмную тему»

В Dvarf **сейчас нет dark mode** (чёрный/тёмный фон всего приложения).

Есть **6 тем аккаунта** на **светлом пергаменте** `#fbf7ec`.  
Тема меняет только:

- `--accent` — кнопки, активные вкладки, заголовки панелей  
- `--accent-soft` — мягкие кнопки, подсветка выбора  

Не меняет: фон, текст ink/muted, danger, цвета характеристик (СИЛ всегда медь и т.д.).

Проверено по живому CSS прода и доскам UI Kit (Листва / Wave A).

## Черновик твоей персональной темы

Заполни или скажи мне в чате — соберу файл + превью.

```text
Имя темы:     ________________  (например «Ночная чернильница»)
База:         Чернила / Слива / Медь / Хвоя / с нуля dark mode
accent:       #________
accent-soft:  #________
Ощущение:     одной фразой «как …»
Где проверить: лист (шапка+Бой) / лобби / кабинет
```

### Правила, которые разработчик почти наверняка попросит соблюсти

1. Меняем **только** accent + soft (если остаёмся в текущей модели тем).  
2. Не перекрашиваем пергамент и danger без отдельного ok.  
3. Характеристики (rail A) не трогаем.  
4. Контраст текста на кнопке: белый на accent должен читаться.  
5. Проверка на листе + лобби + кабинет.

### Если хочешь именно тёмный фон (night)

Это **новый тип темы**, не одна из шести. Нужны отдельно:

- `--bg` / `--panel` / `--ink` для тёмной поверхности  
- правила для HP, бордеров, модалок  
- ok Игоря + доска в UI Kit до кода  

Могу набросать proposal «Night + Чернила» рядом с личной accent-темой.

## Как утвердить с разработчиком (простой пакет)

1. Выбрал базу (Чернила / …).  
2. Есть имя + два hex.  
3. Есть 1 картинка/canvas: кнопка + вкладка Бой + HP.  
4. Короткий текст: «хочу 7-ю тему / заменить X».  
5. Отдаёшь разработчику: этот файл + превью.

Когда скажешь базу — сделаю персональный файл `docs/ui-kit-current/personal/<имя>.md` и canvas-превью.
