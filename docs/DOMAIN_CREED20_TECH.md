## Зачем по шагам (простыми словами)

1. **DNS** — сказать интернету: «creed20.tech = наш сервер».
2. **Nginx на VPS** — принимать запросы с именем creed20.tech (не только по IP).
3. **HTTPS** — замочек в браузере (Let’s Encrypt).
4. **Почта** — ящик **`info@creed20.tech`** (решение Игоря; для `/legal` и связи).
5. **В продукте** — `/legal`, кнопка «Сайт КриD20», ссылки на домен (слайс Legal shell после ok).

Пока DNS не указывает на VPS, домен «пустой» — это нормально на пару часов/дней.

## Шаг 1 — DNS в reg.ru (делаешь ты)

В панели reg.ru → домен **creed20.tech** → управление зоной DNS.

### Минимальная схема (сайт на том же VPS)

| Тип | Имя / хост | Значение | TTL |
| --- | --- | --- | --- |
| **A** | `@` (или пусто / creed20.tech) | `201.34.132.252` | 3600 |
| **A** | `www` | `201.34.132.252` | 3600 |

Если reg.ru предлагает «парковку» или свои NS с заглушкой — для прода нужен **либо** их DNS с такими A-записями, **либо** NS Timeweb (если перенесёшь DNS к хостеру). Проще на старте: **оставить DNS на reg.ru**, только прописать A.

Проверка с любого ПК через ~5–60 минут (иногда до 24ч):

```bash
dig +short creed20.tech A
# должно стать: 201.34.132.252
```

или в браузере: https://www.whatsmydns.net/#A/creed20.tech

На Timeweb в nginx:

- редирект `www` → apex (или наоборот — один канон: **https://creed20.tech**)

Пока в Legal shell слайсе можно писать домен в текстах даже до HTTPS; кнопка сайта до готовности DNS может вести на `/legal`.

## Шаг 3 — почта **info@creed20.tech**

Нужен адрес: **`info@creed20.tech`**.  
Почта reg.ru **не обязательна** (часто дорого) — ниже дешевле/бесплатно.

### Рекомендация для старта (бесплатно)

| Место | Что это | Плюс | Минус | Когда брать |
| --- | --- | --- | --- | --- |
| **1. ImprovMX / Forward Email** | Только **пересылка**: info@ → твой gmail | Бесплатно; DNS остаётся на reg.ru; меняешь в основном **MX** | Это не «свой ящик» в веб-почте; ответы удобнее через Gmail «Отправить как» | **Лучший старт** |
| **2. Cloudflare Email Routing** | То же: бесплатный форвард | Надёжно, бесплатно | Нужно перевести **NS домена на Cloudflare** (осторожнее с A-записями сайта) | Если всё равно хочешь CF для сайта |
| **3. Zoho Mail Free** | Настоящий ящик info@ в Zoho | Свой вход, до ~5 пользователей | Регистрация/верификация домена; IMAP часто на платном | Если хочешь отдельный веб-интерфейс |
| **4. Яндекс 360 для бизнеса** | Ящик на домене | RU-интерфейс; иногда бесплатно до 3 чел. | Тарифы менялись — сверь цену на сайте | Если удобнее Яндекс |
| **5. Почта reg.ru** | Ящик у регистратора | Всё в одном кабинете | Дорого относительно форварда | Если очень хочется «всё в reg.ru» |

Для `/legal` достаточно, чтобы письма **приходили** на info@. Отвечать можно из gmail (на старте ок).

### Вариант ★ — ImprovMX (форвард, DNS на reg.ru) — пошагово

1. Зайди на [improvmx.com](https://improvmx.com) → Free → добавь домен `creed20.tech`.
2. Сервис покажет **MX**-записи (и иногда SPF TXT).
3. В reg.ru → DNS зона creed20.tech:
   - **не трогай** A `@` / `www` → `201.34.132.252`;
   - добавь MX как сказал ImprovMX (удали старые MX, если были от парковки/reg.ru mail);
   - добавь SPF TXT, если просят.
4. В ImprovMX: алиас `info` → твой личный gmail.
5. Подтверди gmail (письмо-ссылка).
6. Подожди 15–60 мин → напиши на `info@creed20.tech` с другого ящика → должно упасть в gmail.

Альтернатива с тем же смыслом: [forwardemail.net](https://forwardemail.net) (тоже форвард + MX на reg.ru).

**Отвечать как info@ из Gmail (по желанию):**  
Gmail → Настройки → Аккаунты → «Отправлять письма как» → добавить `info@creed20.tech`.  
На бесплатном форварде отправка «как info@» иногда через SMTP Zoho/другого — на старте можно просто отвечать с gmail, в `/legal` адрес всё равно info@.

Бери, если планируешь Cloudflare для сайта/HTTPS. Иначе ImprovMX проще (NS не трогаешь).

### Вариант — ящик прямо в reg.ru (дорого, не рекомендуем сейчас)

1. Зайди на [reg.ru](https://www.reg.ru) → авторизация.
2. **Домены** → **creed20.tech** → раздел вроде **«Почта» / «Почта для домена» / «Mail»**  
   (иногда: Услуги → Почта / «Подключить почту»).
3. Если почта ещё не подключена — нажми **подключить / создать** (часто есть бесплатный или недорогой тариф «Почта для домена»).
4. **Создать ящик**:
   - имя: `info`
   - домен: `creed20.tech`
   - пароль: свой надёжный (сохрани в менеджер паролей)
5. Готово: адрес **`info@creed20.tech`**.
6. Открыть веб-почту: обычно `https://mail.reg.ru` или ссылка «Войти в почту» из панели домена.
7. На телефон: IMAP/SMTP — reg.ru покажет готовые серверы в карточке ящика (скопируй в Gmail App / Spark / и т.д.).

**Важно про DNS (сайт на Timeweb + почта на reg.ru):**

| Запись | Зачем | Не трогать |
| --- | --- | --- |
| **A** `@` / `www` → `201.34.132.252` | сайт на Timeweb | не меняй на IP reg.ru |
| **MX** → серверы почты reg.ru | письма на info@ | обычно ставит сам при заказе «Почта на домене» |
| **TXT SPF** | чтобы письма не падали в спам | ставит reg.ru |

Если мастер почты предложит «переключить DNS на ns1.hosting.reg.ru» — **осторожно**: это может сбить твои A на Timeweb. Безопаснее: оставить текущие NS (часто `ns1.reg.ru` / `ns2.reg.ru`) и **добавить только MX (+ SPF)**, не меняя A.
