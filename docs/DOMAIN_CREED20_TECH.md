## Зачем по шагам (простыми словами)

1. **DNS** — сказать интернету: «creed20.tech = наш сервер».
2. **Nginx на VPS** — принимать запросы с именем creed20.tech (не только по IP).
3. **HTTPS** — замочек в браузере (Let’s Encrypt).
4. **Почта** — ящик **`info@creed20.tech`** (решение Игоря; для `/legal` и связи).
5. **В продукте** — `/legal`, кнопка «Сайт КриD20», ссылки на домен (слайс Legal shell после ok).

Пока DNS не указывает на VPS, домен «пустой» — это нормально на пару часов/дней.

## Шаг 1 — DNS в reg.ru (делаешь ты)

В панели reg.ru → домен **creed20.tech** → управление зоной DNS.

### Минимальная схема (сайт на том же VPS)

| Тип | Имя / хост | Значение | TTL |
| --- | --- | --- | --- |
| **A** | `@` (или пусто / creed20.tech) | `201.34.132.252` | 3600 |
| **A** | `www` | `201.34.132.252` | 3600 |

Если reg.ru предлагает «парковку» или свои NS с заглушкой — для прода нужен **либо** их DNS с такими A-записями, **либо** NS Timeweb (если перенесёшь DNS к хостеру). Проще на старте: **оставить DNS на reg.ru**, только прописать A.

Проверка с любого ПК через ~5–60 минут (иногда до 24ч):

```bash
dig +short creed20.tech A
# должно стать: 201.34.132.252
```

или в браузере: https://www.whatsmydns.net/#A/creed20.tech

## Шаг 3 — почта **info@creed20.tech** (reg.ru)

Нужен ящик: **`info@creed20.tech`**.

### Вариант A — ящик прямо в reg.ru (самый простой)

1. Зайди на [reg.ru](https://www.reg.ru) → авторизация.
2. **Домены** → **creed20.tech** → раздел вроде **«Почта» / «Почта для домена» / «Mail»**  
   (иногда: Услуги → Почта / «Подключить почту»).
3. Если почта ещё не подключена — нажми **подключить / создать** (часто есть бесплатный или недорогой тариф «Почта для домена»).
4. **Создать ящик**:
   - имя: `info`
   - домен: `creed20.tech`
   - пароль: свой надёжный (сохрани в менеджер паролей)
5. Готово: адрес **`info@creed20.tech`**.
6. Открыть веб-почту: обычно `https://mail.reg.ru` или ссылка «Войти в почту» из панели домена.
7. На телефон: IMAP/SMTP — reg.ru покажет готовые серверы в карточке ящика (скопируй в Gmail App / Spark / и т.д.).

**Важно про DNS (сайт на Timeweb + почта на reg.ru):**

| Запись | Зачем | Не трогать |
| --- | --- | --- |
| **A** `@` / `www` → `201.34.132.252` | сайт на Timeweb | не меняй на IP reg.ru |
| **MX** → серверы почты reg.ru | письма на info@ | обычно ставит сам при заказе «Почта на домене» |
| **TXT SPF** | чтобы письма не падали в спам | ставит reg.ru |

Если мастер почты предложит «переключить DNS на ns1.hosting.reg.ru» — **осторожно**: это может сбить твои A на Timeweb. Безопаснее: оставить текущие NS (часто `ns1.reg.ru` / `ns2.reg.ru`) и **добавить только MX (+ SPF)**, не меняя A.

Официальные гайды reg.ru:  
[заказать почту на домене](https://help.reg.ru/support/pochta-i-servisy/pochta-regru/kak-zakazat-uslugu-pochta-regru) ·  
[добавить почтовый домен](https://help.reg.ru/support/pochta-i-servisy/pochta-regru/kak-dobavit-pochtovyy-domen) ·  
[создать ящик](https://help.reg.ru/support/pochta-i-servisy/pochta-regru/kak-sozdat-i-nastroit-pochtovyy-yashchik-na-domene)

### Вариант B — только пересылка на gmail (если не хочешь отдельный ящик)

1. В почте домена создай `info@` (как в A) **или** правило «алиас / перенаправление».
2. Включи **пересылку** всех писем на свой gmail.
3. В `/legal` всё равно пишем `info@creed20.tech` — людям виден брендовый адрес.

### Вариант C — позже

Яндекс 360 / Google Workspace для домена — если понадобится «взрослая» почта команде. Сейчас не обязательно.

### Проверка, что почта жива

1. С **другого** ящика (не info@) напиши письмо на `info@creed20.tech`.
2. Оно должно появиться в веб-почте reg.ru (или в gmail, если форвард).
3. Ответь с info@ — ответ должен уйти (если не уходит — смотри SPF в подсказках reg.ru; обычно ставится сам).

## Частые грабли

1. Оставили парковочную страницу reg.ru — A-запись не на VPS.  
2. Прописали только `www`, забыли `@`.  
3. Включили чужие NS и потеряли записи.  
4. Ждёте HTTPS до A-записи — сначала A, потом сертификат.
