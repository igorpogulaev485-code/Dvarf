# Волшебник: книга заклинаний (PHB 2014)

Спека для I-13 / I-16. Код правил: `frontend/src/shared/dnd/wizardSpellbook.ts`.

## Зачем

Сейчас у волшебника есть только `SpellLearnMode = 'spellbook'` и жёсткий лимит `6 + 2×(уровень−1)` на «известные» leveled-заклинания. Нет:

- стоимости/времени внесения в книгу;
- различия «бесплатно при уровне» vs «копия со свитка/чужой книги»;
- физической книги как зависимости;
- копии своей книги (бэкап);
- утери/уничтожения и замены.

## Правила PHB (сжато)

| Ситуация | Правило |
|----------|---------|
| Старт (1 ур.) | 6 заклинаний 1 ур. **бесплатно** в книгу |
| Повышение уровня | +2 заклинания уровня, на который есть ячейки, **бесплатно** |
| Копия чужого (свиток / чужая книга) | **50 зм + 2 часа** за каждый уровень заклинания |
| Копия **своей** книги (бэкап) | **10 зм + 1 час** за каждый уровень заклинания |
| Замена после утери | В новую книгу можно переписать **только подготовленные** по тарифу бэкапа; остальное — искать заново |
| Подготовка | Нужна книга на длинном отдыхе; лимит = Инт + ур. волшебника |
| Каст без книги | Подготовленные + заговоры — да; переподготовка — нет |
| Ритуал | Из книги, **без** подготовки, если есть тег ritual и книга при себе |
| Savant (школа) | Полцены времени и золота для заклинаний своей школы |
| Order of Scribes · Wizardly Quill | 2 мин / уровень ячейки; золотые чернила без стоимости |

> Лимит `6+2×(L−1)` — это **бесплатный** объём исследования, а не жёсткий потолок книги. Платные копии могут превышать его.

## Модель данных

### Расширение `SpellsState`

```ts
wizard_spellbook?: WizardSpellbookState
```

### `WizardSpellbookState`

| Поле | Смысл |
|------|--------|
| `primaryBookItemId` | id предмета «Книга заклинаний» в инвентаре (активная) |
| `bookLost` | книга утеряна/уничтожена |
| `lostBookCatalogIds` | что было в утерянной книге (для UI / мастера) |
| `backupBookItemIds` | id запасных книг |

### Расширение `SheetSpell` (leveled, wizard)

| Поле | Смысл |
|------|--------|
| `spellbook_acquisition` | `starting` \| `level_up` \| `copied` \| `restored` \| `backup_copy` |
| `in_spellbook` | сейчас в **активной** книге (false после утери, пока не восстановлено) |

Заговоры (`level === 0`) в книгу **не** входят — они «известны», как сейчас.

## Функции (чистые)

| Функция | Назначение |
|---------|------------|
| `copySpellCost` | gp + hours (или minutes для Quill) по kind + модификаторы |
| `totalCopyCost` | сумма по списку (бэкап всей книги) |
| `freeBookSlotsAtLevel` | сколько бесплатных слотов даёт уровень (6 на 1, иначе +2) |
| `freeBookCap` | накопленный бесплатный объём `6+2×(L−1)` |
| `wizardSpellAccess` | что можно: prepare / cast prepared / ritual-from-book / add-to-book |
| `markSpellbookLost` | утеря: `bookLost=true`, снять `in_spellbook`, оставить prepared |
| `beginReplacementSpellbook` | привязать пустую книгу из инвентаря |
| `planRestorePrepared` | стоимость переписи подготовленных в новую книгу |

UI (отдельный слайс): GrimoireDialog показывает cost перед «В книгу»; create/level-up — бесплатные слоты без gp; кнопка «Утеряна» / «Сделать копию»; CastSpellDialog блокирует ритуал без книги.

## Потоки

### A. Наполнение (I-16)

1. Create L1 → 6 free picks (`starting`), без gp.
2. Level-up → 2 free picks (`level_up`), без gp, уровень ≤ max slot.
3. Grimoire «В книгу» сверх free-cap → `copied`, показать gp/time, списать золото (когда инвентарь/кошелёк готов).

### B. Копия своей книги

1. Есть активная книга + пустая книга в инвентаре (50 зм).
2. Игрок выбирает заклинания (обычно все).
3. `kind: 'own'` → 10 зм + 1 ч / уровень; цель получает те же spells с `backup_copy`.
4. `backupBookItemIds` += id новой книги.

### C. Утеря / уничтожение (I-13)

1. Мастер/игрок: «книга уничтожена».
2. `markSpellbookLost`: `bookLost`, snapshot contents, `in_spellbook=false` у leveled.
3. Доступ: cast prepared + cantrips; **нельзя** prepare / ritual-from-book / free level-up add.
4. Замена: купить/найти пустую книгу → `beginReplacementSpellbook` → `planRestorePrepared` → внести подготовленные (`restored`) → дальше копии как обычно.

## Кошелёк

Платные копии списывают золото из `inventory.coins` через `spendGpFromPurse` / `resolveSpellbookAddPayment`.

- Хватает денег → автосписание + toast с суммой и остатком.
- Не хватает → **не** вносим в книгу, toast: «Недостаточно золота: нужно X зм, есть Y зм».
- Гримуар на листе получает `coins` + `onCoinsChange` (тот же блок, что «N зм» в шапке стола).

## Свитки (стык I-17)

Каталог даёт «Свиток N уровня» без имени заклинания. При добавлении в инвентарь открывается выбор заклинания → `item.scroll_spell` + имя «Свиток: …».  
В «Управление книгой» → **Внести из свитка**: foreign-тариф (не тратит free research), списание золота, свиток −1.

**Каст со свитка:** из инвентаря или блока «Расходники» на боевой сцене → Сл/атака по таблице DMG, ячейка не тратится, свиток −1. Связанные свитки автоматически попадают в расходники боя.

Ещё не в этом контуре: полный UX контейнера свитков / авто-проверка списка класса.
