# Лобби — хотфикс L06–L07

Живые обновления стола и лобби. Бой, лист и UI стола здесь не чинятся.

## L06

- **Ожидалось:** любое изменение сессии (`session_changed` / `session_event`) и лобби (чаты, заметки, письма) доходит до всех открытых вкладок не дольше 2 с, к какому бы воркеру они ни были подключены.
- **Фактически:** `RealtimeHub` держал сокеты в памяти процесса, а API запускается с `--workers 2`. Запрос на воркере A рассылался только его сокетам, примерно половина обновлений не доходила.
- **Где:** `backend/app/realtime/hub.py`, `backend/Dockerfile` (`uvicorn --workers 2`).
- **Статус (хотфикс L06–L07):** исправлено. Общий канал Postgres `LISTEN/NOTIFY` `dvarf_rt`. Каждый воркер слушает его своим соединением и отдаёт сообщение только своим сокетам. Число воркеров не менялось.

## L07

- **Ожидалось:** каждый получатель видит сессию в своей видимости. Скрытая локация и нераскрытые страницы не уходят игроку. Скрытый бросок мастера (`is_master_roll`) видит только мастер. Личные письма и приватные заметки не рассылаются всем участникам лобби.
- **Фактически:** `session_update` собирался через `_session_detail` от пользователя, который сделал действие, и этим снимком накрывал всех в комнате. Письмо мастеру и тело заметки уходили в общий сокет лобби.
- **Где:** `backend/app/services/lobby.py` (`session_hub.broadcast`), `backend/app/services/chat.py`, `backend/app/services/note.py`, клиенты `useSessionRealtime` / `useLobbyRealtime`.
- **Статус (хотфикс L06–L07):** исправлено. Сервер шлёт сигнал `session_changed` (и `session_event`, если событие не скрытый бросок). Клиент забирает `GET /sessions/{id}` своим токеном, не больше одного запроса в полёте. Письма и заметки — сигналы `letters_changed` / `notes_changed` без текста.

## L18 (часть)

- **Ожидалось:** при посадке противника из бестиария в шаблон копируются сопротивления, иммунитеты, уязвимости и иммунитеты к состояниям.
- **Фактически:** `add_combatants` эти поля карточки не переносил. `deploy_encounter_template` сажает через тот же метод.
- **Где:** `backend/app/services/lobby.py` (`_copy_defenses`, `_parse_combatants`), `SessionCombatantOut`.
- **Статус (хотфикс L06–L07):** исправлено в backend, без миграции и без UI. Игрокам эти поля на столе не показываются (скрытие в ответе API — L10, пачка 12).
