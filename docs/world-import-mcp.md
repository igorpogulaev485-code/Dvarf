# MCP импорта мира (W-API-10)

Удалённый MCP-коннектор Creed20/Dvarf: те же операции, что REST импорта мира
(validate / upsert / git / статус / diff / confirm / undo), подключение **по адресу**.

Общая инструкция для мастера (заливка, приватность, ошибки, `rules_edition=2014`):
[`docs/world-import.md`](world-import.md).
На сайте та же справка: `/help/world-import`.

В каталоги ChatGPT и Claude **ничего не публикуем** — мастер сам вставляет URL
и токен в настройках клиента. Это закрытый коннектор по адресу, не витрина.

## Адрес

После деплоя API:

`https://creed20.tech/mcp/world-import`

Локально (API уже запущен на :8000):

`http://127.0.0.1:8000/mcp/world-import`

Отдельный процесс (без общего uvicorn API):

```bash
cd backend
python -m app.mcp.world_import
```

По умолчанию слушает `127.0.0.1:8100`, путь `/mcp/world-import`
(порт — env `MCP_PORT`).

Протокол: **streamable HTTP** (MCP). В nginx для `/mcp/` уже есть прокси на API.

## Токен

1. Мастер в лобби создаёт токен импорта мира (REST из W-API-01 /
   экран из W-API-11): один раз показывается секрет вида `wapi_…`.
2. В клиенте MCP укажите заголовок:

   `Authorization: Bearer wapi_…`

3. Токен привязан к **одному лобби и сеттингу**. Чужие миры не читает,
   тумблер «ИИ может подтверждать» не включает, пароль и биллинг не трогает.
4. Сырой секрет **не коммитьте** и не вставляйте в чат «на всякий случай».
   В логах сервера токен не пишется.

Параметр инструмента `authorization` — запасной путь, если клиент не умеет
заголовки. Предпочтителен заголовок.

## Инструменты

| Инструмент | Что делает |
|------------|------------|
| `validate_world` | Проверка пакета без записи в канон. **Сначала он.** |
| `upsert_world_files` | Файлы в черновик сверки (`source_kind=mcp`). |
| `import_world_from_git` | Публичная HTTPS git-ссылка (github/gitlab) → черновик. |
| `get_import_status` | Статус задания. |
| `get_import_diff` | Сверка с каноном. |
| `confirm_import` | Запись в канон. Сервер требует включённый тумблер для токена ИИ. |
| `undo_import_confirm` | Откат последнего confirm. |

Общие аргументы: `setting_id` (UUID сеттинга токена), для заданий — `job_id`.
`rules_edition` по умолчанию `2014`; значение `2024` и иное — ошибка
`rules_edition_unsupported`.

## Чего нельзя

- Подтверждать импорт, пока тумблер выключен (ответ `confirm_ai_disabled`).
- Тянуть `file://`, localhost и частные IP через git (`git_url_rejected`).
- Публиковать мир, класть сущности в общий каталог правил, создавать хоумбрю
  рас/классов/заклинаний.
- Класть токены в git или в эту инструкцию.

## Пример порядка для ИИ

1. `validate_world` с файлами markdown.
2. При `ok: true` — `upsert_world_files` (лучше с `idempotency_key`).
3. `get_import_diff` — показать мастеру.
4. `confirm_import` — **только** после явной просьбы мастера или если тумблер включён.
5. При ошибке — `undo_import_confirm`.

## Зависимости и деплой

- Пакет Python: `mcp==1.30.0` (см. `backend/requirements.txt`).
- Отдельный docker-сервис не нужен: MCP смонтирован на том же API
  (`/mcp/world-import`), наружу идёт через существующий edge (Caddy) → web
  (nginx) → api.
- Деплой на прод этим документом не запускается — только владелец через Actions.
