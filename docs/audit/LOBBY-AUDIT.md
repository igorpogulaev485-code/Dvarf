## 1. Карта путей (как есть)

### Мастер

1. `/lobbies` → «Создать» → название → «+ Создать лобби» → хаб.  
2. Сверху блок «Приглашение · код …» (код, ссылка `/join/…`, «Копировать», QR, «Новый код»). Подсказка «С чего начать» (3 шага).  
3. Вкладки: Состав · Дневник · Заметки · Чаты · Сессии · Сеттинг · Настройки (правила кампании/старта, картинки 200 МБ).  
4. «Сессии» → создать сессию → «Живой стол».  
5. «Кто пришёл» → отметить → сохранить. «+ Враги» / бестиарий. «Бой» → инициатива/волны/врасплох → «Начать бой».  
6. «Следующий ход», урон/лечение (число обязательно), стороны, «Завершить бой» → окно «Награды» (опыт + сундук).

### Игрок

1. `/join/КОД` (после входа) → имя лобби + правила старта → выбрать персонажа / «Создать героя…» / наблюдатель → «Сесть за стол».  
2. Хаб участника: состав, дневник, заметки, чаты, сессии; на карточке «Лист» / «Покинуть».  
3. Сессия: своя карточка, «Бросить инициативу», лента, сайдбар заметок/чата/вики; без мастерского тулбара.  
4. «Лист» → броски с листа уходят в сессию (`postSheetRollToSession`).  
5. После боя — то же окно наград с стороны мастера; игрок видит итог в ленте («Партия победила»). Обновление страницы возвращает в сессию.

## 4. Предложения пачками (без раздувания UI) + вопросы к Игорю

### Пачка A — «бой не зависает» (приоритет)
- Автобросок инициативы героя через N секунд или кнопка мастера «бросить за него».  
- Реакцию после урона: default «нет» через 5–10 с или один клик «Пропустить».  
- Подпись у disabled «Урон»: «Введите число».

**Вопрос Игорю:** реакция после каждого урона — оставляем строгий PHB-стоп или делаем opt-in в правилах кампании?

### Пачка B — «награды сами»
- При конце боя заполнять пул XP из CR/XP побеждённых (и своих НПС с заданным XP).  
- Короткий тост игроку: «+N XP», «в сундуке N предметов».

**Вопрос Игорю:** «свой НПС» без карточки бестиария — XP 0 ок, или мастер обязан указать XP при посадке?

### Пачка C — «меньше кликов до боя»
- Опция «все из состава уже за столом» без отдельного «Кто пришёл» на ваншоте.  
- Стартовый пресет: «быстрый бой» = посадить отмеченных + гоблины + старт с автоинициативой.

### Пачка D — «загрузка и мобилка»
- Скелетон стола вместо голого «Загрузка сессии…».  
- На 390: «⋯» ≥44px; не резать back-link по высоте.

### Пачка E — «честная сводка персонажа»
- На join и карточке стола не писать «без класса», если класс есть в sheet; HP не показывать «—», если в листе есть max.

**Вопрос Игорю:** HP героя на столе для мастера всегда цифры, для других игроков — по правилам скрытности L-08?

## Замечания по методике

- Каталог классов на свежей БД агента пришлось локально дозасеять заглушками (ranger/aasimar и т.п.), иначе `alembic upgrade head` падает на content-миграциях — **это среда агента, не баг прода**.  
- Игрок без `email_verified_at` получает 403 «Подтвердите email» — на проде ожидаемо; для аудита верифицировали локально.  
- Сидовый «Воин Игрока» скопирован с CMB-листа; сводка class/HP на столе оказалась дырявой — отдельно от UI-пути.  
- Computer-use доп. проход мог дописать `cu-*` в `/tmp`; канон отчёта — Playwright-кадры в `docs/audit/frames/lobby/`.

## Итог одной фразой

Лобби как «комната + код + хаб» для новичка **в целом собирается**, realtime мастер↔игрок **живой**, но **реальный бой спотыкается** о ручные паузы (инициатива/реакция), **серые кнопки урона** и **пустые награды после победы** — это то, что сильнее всего бьёт по ощущению «система ведёт стол».
