## §13. Юзабилити создания «классического» листа (2014)

**Путь:** список → «Создать персонажа» → `/characters/create` · редакция зафиксирована **D&D 2014** (отдельного выбора 2024 в создании нет — так и задумано).

**Шаги пайплайна (канон):** Раса → (Черта, если раса даёт) → Предыстория → Класс → Характеристики → Прокачка. На экране: «Шаг N из 5», ~20% за шаг без черты.

### Сколько кликов (оценка новичка)

| Этап | Типичные клики | Что путает |
|------|----------------|------------|
| Список → создать | 1 | Онбординг может перехватить первый заход |
| Раса: выбрать карточку | 1 | В списке и расы, и подрасы (дварф / горный / холмовой) — непонятно, что жать первым |
| «Настроить расу» | 1 | |
| Пол + имя + язык + «Применить» | 3–5 | Пол обязателен для генератора имени, но можно ввести имя вручную и забыть пол; сетка языков длинная на 390 |
| Предыстория | 2–6 | После расы тост **закрывает CTA**; длинный список SCAG/GOS |
| Класс + настройки (навыки, снаряжение…) | 5–20 | Зависит от класса; диалоги многошаговые |
| Характеристики | 3–10 | Метод (стандарт/покупка) + раздача |
| Прокачка / готово | 1–4 | |
| **Итого** | **≈ 20–50** | Без тупиков; с тостом на шаге 2 легко «застрять» |

На проходе аудита: раса «Человек» применилась (шаг стал 2/5, 40%). Дальше на 390 упёрлись в тост над «Настроить предысторию» — путь для новичка **ломается по ощущению**.

### Кадры по шагам

| Шаг | 390 | 1440 |
|-----|-----|------|
| Старт / раса | `c13-01-create-start-390`, `c13f-01-start-390` | `c13-01-create-start-1440`, `c13f-01-start-1440` |
| Выбор + настройка расы | `c13f-02…04-*-390`, `c13f-race-setup-*-390` | те же суффиксы `-1440` |
| Предыстория (+ тост) | `c13f-05…07-*-390`, `c13f-14-done-390` | `c13f-*-1440` |
| Класс / дальше | частично `c13f-08…13` (автосъёмка не довела до конца из‑за тоста/диалогов) | то же |

**1440:** модалка расы центрируется нормально, поля читаемы; тот же текст тоста, но CTA менее перекрыт.

## §14. Печать классического листа: формы 2014 и 2024

### Продуктовый путь (персонаж → классический лист)

| | 2014 | 2024 |
|--|------|------|
| Кнопка макета на `/characters/:id/classic` | есть, **disabled**, подпись «печатная форма · D&D 5e 2014» | **нет** |
| «Печать / PDF» | есть, вызывает `window.print()` | — |
| Данные в полях | да (Даррак: имя, жрец 3, дварф горный, солдат, характеристики, КД 17, хиты…) | — |
| 390 | `c14-02-classic-2014-390` … `c14-06-*` | отсутствует |
| 1440 | `c14-02-classic-2014-1440` … `c14-06-*` | отсутствует |

### Пустой бланк `/classic/blank?layout=2024`

Query **игнорируется**: тулбар пишет «макет 2014», кнопка только 2014. Кадры: `c14-07-blank-layout2024-query-390/1440`, `c14-08-blank-toolbar-*`.

### Где 2024 ещё жив

- Компонент `frontend/src/features/classicSheet/ClassicPrint2024.tsx`
- DEV: `/dev/classic-sheet-preview` — переключатель 2014/2024 работает, «Печать / PDF» есть, данные демо-персонажа в полях. Кадры: `c14-10-dev-preview-2024-390`, `c14f-preview-2024-1440`, `c14f-preview-2024-390`.  
  На проде DEV-маршрутов нет → **игроку форму 2024 не открыть**.

### Коммит, где пропала печать 2024

```
a49a5da8  2026-11-13  fix(FIX-01): post-release bugs for wiki, dice-on-table, classic sheet
```

В сообщении явно: «print layout 2014-only». Selfcheck `classicSheetFix01.selfcheck.ts` требует, чтобы страница **не** предлагала 2024.  
Добавление переключателя было раньше: `cb6a8733` (2026-10-16).

**Вердикт §14:** печать **2014 — ок** (превью с данными, кнопка PDF). Печать **2024 в пользовательском UI — сломана/снята** → серьёзность **ломает** относительно требования аудита («обе кнопки/варианта печати»).

## Замечания по методике

- Каталог на свежей БД агента пришлось дозасеять минимально (расы/классы/предыстории), иначе создание было бы пустым — на проде каталог полный.
- Часть кадров с одинаковым md5 — повтор экрана, когда клик не сменил UI (зафиксировано в `manifest-all.json`).
- «Цель атаки» и полный каст с метамагией на 760 стоит перепроверить руками на проде: автоклик чаще попадал в бросок/соседние панели.
- Computer-use доп. проход мог дописать кадры `cu-*`; в этой сборке отчёта опора на Playwright-кадры выше.

## Итог одной фразой

Мобильный лист с 5 сценами в целом живой, но режет тексты в шапке, тосты бьют по кнопкам, а **печатная форма 2024 сознательно выпилена в FIX-01 (`a49a5da8`)** — для требования «печатать 2014 и 2024» это блокер; создание на телефоне дополнительно ломает тост на шаге предыстории.
