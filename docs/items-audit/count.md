# Сверка каталога магических предметов 2014

Дата среза dnd.su: 11.11.2026. Сводка тестера Ильи: 30.10.2026, файл `items_check.xlsx` (агрегаты, без построчного списка). Код не менялся.

Полный перечень карточек и строк каталога: [`inventory.csv`](inventory.csv).

## Откуда цифры

**dnd.su.** Официальный раздел https://5e14.dnd.su/items/ (не Homebrew). Индекс `/piece/items/index-list/` — 934 карточки. У каждой карточки сняты английское имя, русское имя, тип, редкость, плашки источников, строка «настройка», ссылка.

**Creed20.** Не UI. Собрано из JSON так, как это делают миграции:

1. `backend/data/srd/2014/catalog.json` (базовый SRD).
2. Поверх, по порядку волн: `gear_backfill_v1`, `gear_tools_mounts_v1`, `gear_magic_enrich_v1`, `gear_wondrous_srd_v1`, `gear_xge_tce_v1`, `gear_settings_v1`, `gear_dmg_polish_v1`, `gear_family_parents_v1`, `gear_spell_scrolls_4_9_v1`, затем живые ревизии BMT (moonbow, weapons, armor, wondrous), `gear_dmg_artifacts_v1`, пачки `gear_i02`…`gear_i06` включая `gear_dmg_fill_v1`, затем `gear_xge_tce_fill_v1`, `gear_settings_fill_v1`, `gear_other_fill_1_v1` и `gear_other_fill_2_v1`.

Магическая строка: редкость от common до artifact, либо настройка, либо `magic_bonus`, либо непустой `effects`. Обыденный PHB (оружие, доспехи, инструменты, скакуны) не считается. Выключенные строки (`is_active = false`) в «есть» не входят.

Сопоставление: сначала нормализованное английское имя, затем русское. Семьи (`+1/+2/+3`, greater/superior/supreme, цвет чешуи дракона, тип великана) сходятся на одну карточку dnd.su. Отдельные алиасы SRD: Apparatus of the Crab = Apparatus of Kwalish, Efficient Quiver = Quiver of Ehlonna, Handy Haversack = Heward's, Instant Fortress = Daern's, Walloping Arrow = Walloping Ammunition, глаз и рука Векны = одна карточка «Eye and hand of Vecna».

Восемь основных источников — плашки `DMG14`, `XGE`, `TCE`, `EGW`, `FTD`, `SCC`, `RLW`, `GGR`. `DMG24` на той же карточке не делает предмет «только 2024»: если есть `DMG14`, карточка в основных.

## Сравнение с цифрами Ильи (30.10.2026)

| | Илья | Этот срез |
| --- | ---: | ---: |
| Карточек dnd.su без Homebrew | 934 | 934 |
| Из 8 основных книг | 508 | 506 |
| Уникальных названий Creed20 | ~381 по UI | 458 строк / 356 семей |
| Точных совпадений | 155 | 309 карточек по имени (308 EN + 1 RU) плюс 46 карточек семьёй/алиасом |
| Кандидаты | 59 + 119 | не использовались: остаток либо дыра, либо 14 «лишних» |
| Без совпадения | 601 | 579 карточек |

Расхождения объясняются методом, не тем, что каталог вырос за две недели (JSON предметов в коммитах после 30.10 не менялся; на `main` от 11.11 менялись каст и инфузии, не список предметов).

- **508 против 506.** Плашки на карточках дают 506. Две карточки Илья, видимо, отнёс к основным иначе (другая плашка или ручная правка). Список плашек в срезе: DMG14 282, XGE 48, TCE 46, EGW 46, GGR 34, RLW 24, FTD 17, SCC 9.
- **~381 против 458/356.** Илья считал названия с UI. Пикер группы семей свёрнуты (356 групп). Часть строк в UI могла не попасть в выгрузку. JSON после всех волн — 458 активных магических строк.
- **155 точных против ~355 закрытых карточек.** Сверка Ильи шла по русским подписям UI и рвалась на «+1», скобках и порядке слов. Здесь ключ — английское имя из каталога, поэтому DMG/SRD сходится пачкой, а не половиной.
- **601 против 579.** Та же дыра по приключениям и недобору TCE/EGW/GGR. Разница в 22 карточки — это семьи, которые Илья не склеил (зелья лечения, оружие +N, камни Иоун, чешуя дракона).

## Семя и живой Alembic

Волны по-прежнему описаны JSON в `backend/data/srd/2014/`. Архивные ревизии в `backend/alembic/archive_forms_adapt_versions/` на путь Alembic не возвращаются.

Живая миграция `i01seed8f2a7` вызывает `apply_gear_catalog_waves`: upsert волн в порядке раздела «Откуда цифры», затем правки I01 (палочка вязких шаров и 13 выключенных строк). Повторный прогон — 0 изменений. Как добавить предмет: [`README.md`](README.md).

После I22 активных магических строк 445 (458 минус 13 скрытых). Скрытые строки в базе остаются. Волны `gear_i*` после этого среза добавляют только свои `inserts`; живой счёт — 445 плюс те вставки, которые остались активной магией.
