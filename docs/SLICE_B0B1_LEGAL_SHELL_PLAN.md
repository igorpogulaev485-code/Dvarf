## Цель слайса

Положить **первый видимый юридический каркас** и **разметку каталога по слоям** — **без** удаления справочников и **без** paywall.

На пальцах:  
игрок по-прежнему видит расы/спеллы/монстров;  
появляется честная страница «Правовая информация» + ссылка в подвале;  
в данных у каждой сущности появляется ярлык `content_layer` (для нас и будущих щитов).

---

## Что строим / меняем

### A. B0 — ярлыки на каталог (невидимое игроку ядро)

1. Правило разметки (уже в `KEEP_CATALOGS_PLAYBOOK.md`):
   - `srd` — реально из SRD
   - `community_ref` — официальные книги вне SRD (**оставляем, бесплатно**)
   - `user_import` / `homebrew` — как есть
2. Технически: поле `content_layer` (и при возможности флаг `has_long_prose`) на записях каталога **или** параллельный tag-index, если колонка в БД дороже для первого слайса.
3. Скрипт/миграция: проставить слой по `source` / allowlist SRD (спеллы с `srd-5.1` → `srd`; PHB-gap / ttg:MM / расы книг → `community_ref`).
4. **Ничего не удаляем** из каталога.

### B. B1 lite — видимая оболочка

1. Публичная страница **`/legal`** (простой русский):
   - кто мы (creed20 / неофициально);
   - SRD: атрибуция CC-BY (стандартная фраза);
   - community reference: справочник бесплатен, не endorsed by Wizards;
   - деньги (когда появятся) = сервис, не доступ к книгам;
   - email для жалоб (завести / указать).
2. Ссылка «Правовая информация» в подвале (footer) основных экранов кабинета/листа — **без** ломки UI kit.
3. Короткий дисклеймер в подвале: «Неофициальный фан-проект. Не связан с Wizards of the Coast.»

### C. Документы в репо (в том же PR)

- Обновить `PRODUCT_STATUS` **только после** проверки на проде (не заранее «да»).
- Ссылка из `/legal` не обязана тащить все MD на сайт.
