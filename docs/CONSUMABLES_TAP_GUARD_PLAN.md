# План: защита расходников от случайных тапов

**Статус:** ✅ на проде · tip `cursor/consumables-tap-guard-plan-3b91` · 2026-10-21  
**Контур:** план → ok → код → скрины → ok → **прод**  
**База:** live tip (влит `vpn-https-stable-fab2` перед деплоем)  
**Где болит:** Play Desk → Атаки → блок «Расходники»  
**Фидбек:** случайный тап сразу тратит; после траты непонятно, *что* ушло; «нет защиты от случайных тапов». Второе сообщение: путаный флоу «уменьшение → confirm → qty» и снова «хз какой предмет».

---

## Цель (простыми словами)

В бою расходник можно потратить **быстро**, но:

1. случайный тап **обратим** несколько секунд;
2. всегда видно **имя** предмета, который ушёл;
3. трата не срабатывает от тапа по названию строки.

Скорость «−1 болт» не заменяем тяжёлым confirm на каждый тап.

## Как сейчас (замер в tip)

| Место | Поведение |
| --- | --- |
| `PlayDeskAttacksCompact` | Вся строка расходника = одна кнопка → сразу `onSpendConsumable(id)` (−1) |
| `MinimalSheetEditor` | −1 в inventory + тост `−1 «{name}» · осталось N` / `кончилось` |
| `Toast` | Только строка текста, клик закрывает; **нет** action / Undo |
| Свитки | Уже через `CastScrollDialog` (confirm + израсходовать) — **не трогаем** |
| Ресурсы в том же блоке | Тоже one-tap «потратить» — **вне этого слайса** (отдельный follow-up) |
| Инвентарь | `NumberInput` на qty без pad; pad (`NumberPadDialog`) есть для HP/монет |

## Что войдёт в слайс

Два закрываемых куска. **A — обязательный.** **B — по ok**, если хотим qty>1 без спама тапами.

### A. Tap-guard + Undo (MVP)

| # | Работа | Зачем |
| --- | --- | --- |
| A1 | Разделить hit-target в строке расходника | Имя / qty — не action (тост «×N» или ничего). Тратит только чип **«потратить»** (меньшая зона). Срезает мисклики по тексту |
| A2 | Расширить тост: опциональный action | `Toast`: `actionLabel` + `onAction` (и дольше держать ~7–8 с при action). Клик по тексту по-прежнему закрывает; клик по кнопке — Undo, без закрытия «мимо» |
| A3 | Spend с Undo-сессией | После −1: тост `−1 «Болты арбалета» · осталось 17` + **Отменить**. Undo возвращает qty (+1), чистит сессию. Новый spend заменяет предыдущий Undo (одна активная сессия) |
| A4 | Имя всегда в тосте | Уже есть — зафиксировать в acceptance; без имени Undo не считается готовым |

**Флоу A (целевой):**

```text
тап «потратить» → сразу −1 → тост с именем + «Отменить» (~7–8 с)
                                 ↓
                         Отменить → qty обратно
```

### B. Qty pad для «потратить несколько» (опционально, после A)

| # | Работа | Зачем |
| --- | --- | --- |
| B1 | Long-press / второй жест **или** мелкий контрол «×N» | Открыть pad с **названием предмета в title** |
| B2 | Pad: qty (дефолт 1) → **Потратить** | Порядок: предмет → количество → confirm. **Не** «уменьшение → confirm → qty» |
| B3 | После pad-spend — тот же Undo-тост | Одна модель обратной связи |

Переиспользовать паттерн `NumberPadDialog` / диалогов pad (как HP), не плодить третий keypad с нуля, если можно тонко обернуть.

**Если B не ок в этом слайсе** — только A; qty>1 = несколько тапов + Undo на последний.

## Что не войдёт

| Тема | Почему |
| --- | --- |
| Confirm-диалог на каждый −1 патрона | Убьёт UX боя |
| Те же Undo для ресурсов / ячеек / ки | Другой домен; отдельный план |
| История трат / журнал инвентаря | Полезно, но шире MVP |
| Менять избранное (0/3) / авто-детект расходников | Уже ок |
| Менять флоу свитков | Уже confirm |

Минимальный контракт тоста (эскиз):

```ts
type ToastState = {
  message: string
  durationMs?: number
  actionLabel?: string
  onAction?: () => void
} | null
```

Host’ы, где `toast: string | null`, расширяем совместимо (строка = как сейчас) **или** только CharacterDetail / Play Desk path — что меньше диффа при ok.

## Acceptance

### A

- [ ] Тап по **имени** расходника не тратит qty  
- [ ] Тап по **«потратить»** → −1 сразу, без модалки  
- [ ] Тост содержит **имя** предмета  
- [ ] Пока тост жив, **Отменить** возвращает qty  
- [ ] Истёк тост / закрыт без Отменить → трата окончательна  
- [ ] Свиток по-прежнему открывает cast-диалог, не Undo-−1  
- [ ] Мобильная ширина: чип «потратить» нажимается пальцем (не ≤ ~32px в одну ось без padding)

### B (если в слайсе)

- [ ] В pad title видно имя предмета **до** confirm  
- [ ] Порядок: qty → Потратить (не наоборот)  
- [ ] После confirm — Undo как в A  

### Скрины после кода (до второго ok)

1. Строка расходника: имя отдельно, «потратить» отдельно  
2. После тапа: тост с именем + «Отменить»  
3. После Отменить: qty как было  
4. (Если B) pad с title «Болты арбалета» / аналог
