## Откуда брать вид листа

| Источник | Роль | Можно ли «нарисовать свой» |
|----------|------|----------------------------|
| **Живой прод** http://201.34.132.252/ | пиксельный эталон UI | **нет** |
| **UI-kit доски** `docs/ui-kit/boards/` | контракт шапки / хрома / спеллов / атак… | **нет** |
| **Код tip** `MinimalSheetEditor` + `PlayDeskHeader` + `PlayDeskHotBar` + stage panels | единственная реализация | **нет** новых «листов» |

Классический бланк (`/classic`) — **отдельный print-UI**, не замена Play Desk. См. [`CLASSIC_SHEET_PROD.md`](CLASSIC_SHEET_PROD.md).

Ветка `main` / localStorage-SPA / чужие «упрощённые листы» — **не эталон** и не демо цифрового стола.

---

## Что считается листом на проде

Полный **Play Desk**:

1. Шапка LOCK — `PlayDeskHeader` (§2b, доска `desk-header-lock`)
2. Сцены / вкладки + хром — доска `desk-chrome`
3. Rail характеристик (вариант A)
4. Hot-bar LOCK (§2l)
5. Панели сцен: Бой / Исследование / Общение / … по своим LOCK (§2c–2i)
6. Редактор: `MinimalSheetEditor.tsx` — не параллельный layout

Компакт «Заклинания» — **часть** этого стола, не отдельная страница «листа».

## Жёсткий запрет для агентов

**Запрещено** без явного ok Игоря:

1. Создавать `/dev/*`, Storybook, «превью пути», mock-страницы, где есть **фальшивая шапка / «стол персонажа» / упрощённый desk**, не совпадающий с продом.
2. Показывать Игорю скрины такого фейка как «вот так выглядит лист / путь на столе».
3. Делать второй layout листа (dashboard, newspaper, «упрощённый SPA», classic-as-digital).
4. Копировать UI из ЛСС/других приложений как layout стола (ЛСС = только референс поведения, не визуал Dvarf).
5. Деплоить / мержить CSS или компоненты листа с параллельной ветки без merge **live tip**.

**Разрешено** для промежуточной сверки фичи:

- Скрин **живого прода** (после деплоя) или полного Play Desk с tip (логин + реальный персонаж).
- Скрин **одного Dialog** (Гримуар / Новое заклинание) на нейтральном фоне — **без** обёртки «якобы стол».
- Доски из `docs/ui-kit/boards/` как эталон.

Подпись на скрине обязательна: `prod` | `tip Play Desk` | `dialog-only` | `ui-kit board`.
