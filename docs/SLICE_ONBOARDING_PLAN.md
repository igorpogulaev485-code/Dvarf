## Зачем (одной фразой)

Абсолютный новичок сказал: «круто, но ничего не понятно».  
Онбординг закрывает разрыв между «вау» и «я знаю, что делать дальше» — без энциклопедии на 40 шагов.

Слоган продукта: **до приключения — шаг / клик**.  
Онбординг = маршрут к первому понятному персонажу и первому жесту за столом, а не тур по всем полям листа.

---

## Проблема, которую чиним

| Что слышим | Что на самом деле |
| --- | --- |
| «Ничего не понятно» | Нет маршрута: куда жать первым, что обязательно, что можно потом |
| «Круто» | UI/атмосфера ок — проблема не в красоте |
| «Объясни каждый блок» | Симптом: densе лист + D&D-жаргон без контекста |

Два разных «непонятно» (нельзя лечить одним туром):

1. **Продукт** — где список, создание, лист, лобби, что сохраняется.  
2. **Правила D&D** — что такое КД, концентрация, владение, ячейки.

Онбординг продукта ведёт жестами. Правила — коротко *по касанию*, не PHB внутри тура.

---

## Цель и non-goals

### Цель

Новичок за **один заход** понимает:

1. Что это за продукт (лист + стол, не энциклопедия).  
2. Что сделать первым (создать → заполнить ядро → открыть лист).  
3. Зачем ключевые блоки на листе *в момент, когда он до них дошёл*.  
4. Куда идти дальше (стол / дозаполнить / справка).

### Non-goals (явно не делаем)

- Тур из 30+ шагов по всем панелям в первый вход.  
- Встроенный учебник PHB / замена мастера.  
- Обязательный онбординг для тех, кто уже знает LSS/Beyond.  
- Параллельная «вторая UI» только для новичков.  
- Переписывать create-pipeline с нуля (он уже есть как онбординг *создания*).

---

## Принципы (creed20 / iPhone, не LSS)

1. **Маршрут > энциклопедия.** Сначала «что дальше», потом «что это поле».  
2. **Объясняй при касании.** Help у блока, когда человек туда попал / блок пустой / first-run.  
3. **Один жест за раз.** Один CTA на экране онбординга.  
4. **Skip всегда.** «Пропустить» / «Я знаю» с первого экрана; состояние в профиле/`localStorage`.  
5. **Два слоя текста:** *что это* (1 строка) + *зачем тебе* (1 строка) + опционально *если не знаешь — поставь X*.  
6. **Create = главный онбординг персонажа.** Лист не учит создавать с нуля — он учит *играть* и *дозаполнять*.  
7. **Не дублировать** `GuidedWizard` / create-pipeline: они про выборы правил; этот слайс — про понимание продукта и блоков UI.

## Карта поверхностей (что объясняем)

### A. Вход в продукт

| Экран | Сейчас | Нужно |
| --- | --- | --- |
| Логин / регистрация | Формы есть | 1 строка ценности под брендом: «Лист и стол D&D — до приключения один клик» |
| Список персонажей (пустой) | Create кнопка | EmptyState: зачем список + CTA «Создать первого» + secondary «Как это работает» |
| Список (есть персонажи) | Ок | Без тура; опциональный «?» в шапке → справка |

### B. Создание (уже почти онбординг)

Источник правды: [`create-pipeline.md`](create-pipeline.md) + [`guided-onboarding-wizard.md`](guided-onboarding-wizard.md).

| Шаг create | Что добавить (копирайт, не новая механика) |
| --- | --- |
| Выбор редакции | «2014 — классика столов СНГ; 2024 — новые правила. Потом можно сменить на листе.» |
| Раса | *Что:* кто ты по крови/народу. *Зачем:* скорость, ТЗ, языки, особенности. |
| Черта (если есть) | *Что:* особое умение. *Зачем:* только если раса даёт с 1 ур. |
| Предыстория | *Что:* кем был до приключения. *Зачем:* навыки и владения «из прошлого». |
| Класс + setup | *Что:* чем занимаешься в бою/партии. *Зачем:* хиты, спасброски, умения, снаряжение. |
| Характеристики | *Что:* шесть чисел личности/тела. *Зачем:* почти все проверки и бой. Default: массив 15–14–… |
| Прокачка | *Что:* уровни и развилки. *Зачем:* если стартуешь не с 1. |
| Готово | Экран-мост: «Персонаж готов» → primary «Открыть лист» / secondary «Как читать лист (2 мин)» |

### C. Цифровой лист / Play Desk (ядро «блоки»)

Не tour всего. **Три волны подсказок** + словарь по `?`.

#### Волна 1 — first-run на листе (≤ 5 шагов, skip)

Порядок coachmarks (один spotlight за раз):

| # | Блок | Что | Зачем | Почему сейчас |
| --- | --- | --- | --- | --- |
| 1 | Боевая шапка (КД / хиты / инициатива) | Живые числа боя | Видишь «жив ли герой» без скролла | Без этого лист = бланк |
| 2 | Режимы стола (Бой / Исслед. / …) если есть | Контекст «что делаем сейчас» | Прячет лишнее, показывает нужное | Иначе всё сразу |
| 3 | Характеристики + навыки (glance) | Шесть статов и умения | Сюда смотрит мастер на проверках | База D&D |
| 4 | Атаки / каст (что релевантно классу) | Жесты «ударить / колдовать» | Это «играть», не заполнять | До приключения — клик |
| 5 | Чеклист «ещё можно» | Список незаполненного | Не обязан сейчас; можно вернуться | Снимает тревогу «не всё заполнил» |

#### Волна 2 — inline help у панелей (по `?` / empty)

Для **каждой** панели — карточка help (title / what / why / if unsure).  
Показывается: клик `?`, или empty-state панели, или first open панели.

Инвентарь блоков (цифровой лист, актуально tip):

| Блок UI | Что это | Зачем тебе | Если не знаешь |
| --- | --- | --- | --- |
| Боевая шапка | КД, скорость, хиты, инициатива, вдохновение, Conc | Всё критичное в бою в одном месте | Хиты = «сколько держишь ударов»; КД = «насколько трудно попасть» |
| Основное | Имя, раса, классы, фон, мировоззрение, размер, опыт | Кто ты на столе и для мастера | Имя + класс + раса достаточно для старта |
| Пассивные чувства | Пассивное внимание / проницательность / расследование, ТЗ | Мастер кидает «втайне» — ты уже «готов» | Оставь авто-счёт |
| Владения снаряжением | В чём доспехах/оружии умеешь | Без владения — помехи / сюрпризы правил | Возьми из класса (create) |
| Языки и инструменты | На чём говоришь / чем владеешь | Соц. сцены и проверки инструментов | Общий + от расы/фона |
| Характеристики | СИЛ ЛОВ ТЕЛ ИНТ МДР ХАР | База почти всего | Массив 15–14–13–12–10–8 |
| Спасброски | Проверки «устоять» | Ловушки, заклинания, яд | Включи владения от класса |
| Навыки | Умения с модификаторами | Исследование, общение, скрытность… | Клик: нет → владение → экспертиза |
| Состояния / истощение | Дебаффы и усталость | Иначе забудешь штраф в бою | Пусто = ок |
| Отдых | Короткий / продолжительный | Восстановить хиты и ресурсы | Спроси мастера, когда отдыхаете |
| Атаки | Оружие и удары | Основной жест боя | Добавь оружие из инвентаря |
| Инвентарь + вес | Что несёшь; КД от доспеха | Надел — КД сам; вес — «не перегружен?» | Надень доспех класса |
| Аттюнмент | До 3 магических предметов | Лимит «настроенных» вещей | Пока пусто — норма |
| Заклинания | Ячейки, подготовка, каст, Conc | Каст как за столом | «От класса» для ячеек; подготовь 1–2 простых |
| Текстовые блоки | Внешность, черты, заметки | Роль и лор | 1–2 предложения внешности |
| Напарники / формы (если есть) | Спутники, wild shape и т.п. | Когда класс/фича это даёт | Скрой/пропусти, если не твой класс |
| Classic / печать | Тот же персонаж на бланке | Печать/PDF без второго героя | Потом |

#### Волна 3 — словарь и «Как это работает»

Отдельная лёгкая страница/drawer `/help` или модалка из шапки:

- Карта продукта (Список → Создание → Лист → Лобби).  
- 10–15 терминов (КД, БМ, Conc, ячейка, владение, экспертиза, короткий отдых…).  
- «Я новичок в D&D» → ссылка/абзац: найди стол / мастера; КриD20 не заменяет игру.

### D. Лобби / стол (вторая сессия, не первый экран)

| Момент | Подсказка |
| --- | --- |
| Пустой список лобби | «Стол = место, где играют вместе. Создай или войди по коду/QR.» |
| Первый join | 1 coachmark: код/QR → посадка персонажа |
| Не в N0 first-run | Только после «Персонаж готов» или 2-го визита |

```ts

  version: 1
  segment: 'dnd_new' | 'product_new' | 'skip' | null
```

## Копирайт: шаблон на все блоки

Единый формат (коротко, по-русски, без «инженерного» тона):

```text
Заголовок блока
Что это — одно предложение.
Зачем тебе — одно предложение про стол/игру.
Если не знаешь — конкретный safe default или «спроси мастера / вернись позже».
```

Пример (КД):

> **Класс доспеха (КД)**  
> Число, которое должен побить враг, чтобы попасть.  
> Нужен каждый бой — смотри в шапку, не ищи по листу.  
> Не уверен — надень доспех из снаряжения класса: КД посчитается сам.

Запрещено в copy: стены правил, отсылки к страницам PHB как обязательное чтение, сарказм, англ. без перевода (Conc → «концентрация»).

## Метрики успеха

| Метрика | Как понять |
| --- | --- |
| Novice activation | % новых юзеров с ≥1 персонажем, у кого заполнены имя+раса+класс+характеристики |
| Tour completion / skip | Не цель = 100% complete; цель = низкий rage-quit + высокий «дошёл до листа» |
| Help usefulness | Открытие `?` без немедленного закрытия продукта; качественный вердикт новичка |
| Качественный тест | Повтор с тем же новичком (или аналогом): «теперь понятно, что делать» без ведущего |

Не оптимизируем: длину тура, число tooltips, «прочитал все статьи».

## Риски

| Риск | Митигация |
| --- | --- |
| Тур раздражает опытных | Сегмент + skip + remember |
| «Объяснить всё» = простыня | Cap волны 1 на 5 шагов; остальное по `?` |
| Дубль с create-wizard | Разделение ролей в доке; O1 только copy на create, не новый wizard |
| Overwrite tip | Код только от live tip + preflight |
| Устареет copy при новых панелях | Словарь copy.ru + чеклист «новая Panel → строка в словаре» в AGENTS/skill |
