# Тёмный chrome — исследование и предложение

**Статус:** на согласование. Код не трогаем.

## Почему прошлые A–F казались однотипными

Все были одной формулой: `тёмная панель + один приглушённый акцент` (лес / графит / свеча / чернила / кожа / сланец). Менялся только оттенок акцента — школа одна.

## Что говорят зрелые dark-системы

| Школа | Идея | Примеры |
|-------|------|---------|
| **Product / Material** | Не чистый чёрный; иерархия поверхностей (светлее = выше); акцент менее насыщенный, чем в light | Material 3 tonal surfaces, GitHub Dark `#0d1117` / `#161b22` / accent `#58a6ff` |
| **Arctic / Nord** | Сине-серые «полярные» нейтрали + мягкий frost-акцент | Nord `#2e3440` / `#3b4252` / `#88c0d0` |
| **RPG torchlight** | Тёплый уголь + текст цвета пергамента + **один** акцент (латунь или кровь/ржавчина) | Dungeon Crawl, Quest Journal «Ancient Leather» |
| Neon / Dracula | Яркие насыщенные акценты на dark | **Исключаем** (твоё решение) |

Практики (Atmos / Material): не `#000`, не чистый `#fff` для текста; на dark снижать насыщенность акцента; elevation через тон поверхности, не через «неоновое свечение».

## Предложение для Dvarf (новый набор G/H/I)

Один бланк рядом с классическим листом → важны **разные системы**, не «ещё один зелёный».

| id | Школа | Ощущение | Риск рядом с пергаментным листом |
|----|-------|----------|-----------------------------------|
| **G** | Product dark | Знакомый «как GitHub» | Холоднее кита; зато самый привычный dark |
| **H** | Arctic / Nord | Тихий северный | Далеко от Листвы; очень узнаваемый жанр |
| **I** | Torchlight RPG | Ночь / кожа / факел | Лучше всего стыкуется с бланком и D&D |

**Рекомендация исследователя:** для Dvarf стартовать с **I** (атмосфера + стык с листом) или **G** (если важнее «обычный продукт»). **H** — если хочется заметно другой характер, не фэнтези-таверну.

Неон / Dracula / Catppuccin mauve — не предлагаем как базу.
