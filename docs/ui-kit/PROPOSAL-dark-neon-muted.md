# Приглушённый неон — 3 школы (V / W / X)

Доска: [`boards/dvarf-ui-kit-dark-chrome-compare-neon-muted-VWX.jpg`](boards/dvarf-ui-kit-dark-chrome-compare-neon-muted-VWX.jpg)

Практика dark mode: на тёмном фоне насыщенность акцента снижают (~−20…40), иначе «вибрация» и усталость глаз. Приглушённый неон = тот же приём «hero accent», но без кислоты.

| id | Школа | Акцент | Ощущение |
|----|-------|--------|----------|
| **V** | Soft signal | один мягкий mint/teal | шёпот неона, ближе к продукту |
| **W** | Soft twin | пыльная роза + тихий cyan | cyberpunk без кислоты |
| **X** | Soft HUD | латунь / мёд | HUD-намёк, теплее |

Рядом с пергаментным листом реалистичнее **V** или **X**.
