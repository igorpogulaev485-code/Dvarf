# Вирра v2 — макеты для Figma

Пакет можно открыть/импортировать в Figma без плагинов.

## Как открыть

### Вариант A — SVG (редактируемые фреймы)
1. Figma → **New design file**
2. Перетащи файлы из `svg/` на холст  
   или **File → Place image…** / drag & drop
3. SVG станет фреймами/векторами — можно править цвета, текст, скругления

| Файл | Размер | Экран |
|------|--------|-------|
| `svg/00-tokens.svg` | 960×540 | токены |
| `svg/01-moi-personazhi.svg` | 390×844 | Мои персонажи |
| `svg/02-kabinet.svg` | 390×844 | Кабинет |
| `svg/03-interaktivnyj-list.svg` | 1280×800 | Интерактивный лист / стол |

### Вариант B — PNG/JPG референсы (как картинки)
Папка `png/` — визуальные эталоны (как согласованные доски).  
Удобно положить рядом со SVG как **reference** слой.
