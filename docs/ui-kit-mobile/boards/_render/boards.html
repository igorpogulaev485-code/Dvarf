Правила shell

  1. Одна сцена — никогда не стек всех панелей Wave A.
  2. Bottom Nav — имена как desktop ModeTab; short label под иконкой ок.
  3. HP — крупнейший tap; pad = bottom sheet.
  4. Свернуть vitals — ▴ → compact (who · HP · chip · ▾); больше места сцене.
  5. Характеристики — chip → полноэкранная страница (B), не sheet / не tab.
  6. HotStrip — состояния · концентрация · пипы; остаётся при collapse.
  7. Расходники — блок под атаками в Бою (★ из Исследования, до 3).
Collapsed strip: Т · Торин · 28/28 · СИЛ… · ▾ — pads HP/монеты/отдых всё ещё доступны.
Не делать: left drawer владений · путать tab «Способности» с характеристиками · прятать расходники · 6-й tab ЕЩЁ.

3 · Правила mobile

  1. Те же секции, что desktop LOCK §2k.
  2. На телефоне — bottom sheet (не center xl dialog).
  3. Level-up / архетип / расовые выборы — внутри этого sheet.
