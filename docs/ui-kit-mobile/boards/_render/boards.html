Правила shell

  1. Одна сцена — никогда не стек всех панелей Wave A.
  2. Bottom Nav — имена как desktop ModeTab; short label под иконкой ок.
  3. HP — крупнейший tap; pad = bottom sheet.
  4. Монеты / Отдых — в vitals (паритет header).
  5. HotStrip — состояния · концентрация · пипы ресурсов.
  6. Default tab при открытии листа — Бой (time-to-attack).
  7. Характеристики — chip в vitals → sheet (не tab «Способности»).
  8. Расходники — блок под атаками в Бою (★ из Исследования, до 3).
Не делать: left drawer владений · center-modal pads · возврат select «Панель» · путать tab «Способности» с характеристиками · прятать расходники боя.
