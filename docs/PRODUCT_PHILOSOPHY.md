## 1. Бренд creed20 — этимология и смысл

Цепочка, которую нельзя размывать:

| Слой | Значение |
|------|----------|
| **Крит** | Устоявшееся RU-сокращение: **критический бросок** |
| **КритD20 / КриD20** | Крит + двадцатка |
| **КД** | Устоявшееся RU-сокращение: **класс доспеха** (в продукте — живой жест, не каламбур ради каламбура) |
| **К20** | Куб 20 (как говорят за русским столом) |
| **D20** | dice 20 |
| **К20 + D20 → KD20 → КриD20 → creed20** | Звучание и написание сходятся в домене |
| **Creed** (EN) | **Кредо / убеждение / вера** |

**Кредо бренда:** каждый бросок двадцатки создаёт историю.

**Сайт:** creed20.app  

Имя продукта в коде/репо сейчас — **Dvarf**; **creed20** — кредо, домен и внешний посыл. Не плодить третье имя без явного решения Игоря.

## 2. Миссия и слоганы

| | Текст |
|--|--------|
| **Миссия** | Сделать D&D простым для каждого |
| **Слоган A** | До приключения всего шаг |
| **Слоган B** | До приключения всего клик |

Слоганы = одно обещание: от «хочу играть» до живого стола — минимум трения (шаг / клик), не «сначала выучи тул».

## 3. Как creed20 задаёт отстройку от LSS

Аналогия **iPhone vs Android** и бренд **creed20** — одна логика:

| creed20 | Следствие для продукта | Vs LSS |
|---------|------------------------|--------|
| Каждый d20 → история | Жесты вокруг **броска, сцены, последствий** (каст, Conc, бой, лут, лор mid-session) | Не конструктор формул ради формул |
| Сделать D&D простым | Дефолты из правил/справочника; новичок не «инженер листа» | LSS ≈ Android: можно докрутить всё |
| До приключения — клик | Онбординг, создание, join по QR, каст, посадка врага — **один ясный жест** | Не «открой 5 панелей настроек» |
| Кредо / вера | Продукт верит в стол и историю, не в максимализм рычагов | Сверхнастройки излишни, если базовый жест верен |

**LSS ≈ Android:** постоянно хочется «ещё вот это докрутить»; сила — в инструментах.  
**Dvarf / creed20 ≈ iPhone:** взял — удобно; донастройки возможны; сверхнастройки излишни.

**Цель:** не выиграть у LSS числом рычагов. Выиграть тем, что за столом **не думаешь про тул** — думаешь про историю, которую пишет d20.

## 4. Правило для агентов / дизайна

1. Новый рычаг / формула / «режим эксперта» — только если без него **ломается удобный жест**.
2. Сначала: правильный дефолт из справочника/правил (ячейки, КД, раса, слоты).
3. Потом: одна понятная донастройка (override), не язык формул.
4. Сверхнастройки LSS-стиля не копировать «на всякий случай».
5. Если фича есть у LSS, спросить: *это Android-крутилка или creed20-удобство («до приключения — клик»)?* Бери только второе.
6. Любой экран создания / join / каста / боя проверять слоганом: **можно ли сократить до одного клика/шага без потери смысла?**

## 5. Где creed20 уже видно в продукте

| Жест | Почему это «до приключения — клик» |
|------|-----------------------------------|
| Ячейки «От класса» | Не считаешь таблицу PHB руками |
| КД от доспеха/щита | Надел — пересчиталось; override если надо |
| Раса из справочника | Скорость/ТЗ/языки сами |
| Каст с upcast + Conc в шапке | Как за столом, без конструктора |
| Play Desk режимы (Бой/Исслед./…) | Контекст сессии, не панель всех настроек |
| Join по коду/QR | До стола — клик, не анкета |
| Classic = тот же sheet | Не два персонажа «для печати» и «для игры» |
| Handoff стол → сеттинг | История боя не теряется |
