# Dvarf — философия продукта vs Long Story Short

Зафиксировано со слов Игоря (2026-10-17).  
Главный конкурент на СНГ: **Long Story Short (LSS)**.

---

## Аналогия: Android vs iPhone

| | **LSS ≈ Android** | **Dvarf ≈ iPhone** |
|--|-------------------|---------------------|
| Ощущение | Можно настроить всё; постоянно хочется «ещё вот это докрутить» | Взял — и удобно. Тонких настроек меньше |
| Путь мастера/игрока | Куча инструментов → сам собираешь удобство | Качественное удобство уже учтено |
| Сверхнастройки | Норма и сила продукта | Излишни, если базовый жест уже правильный |
| Риск | Пользователь уходит в «инженерство листа» | Не дожать дефолты → кажется «мало функций» |

**Цель Dvarf:** не выиграть у LSS количеством рычагов.  
Выиграть тем, что за столом **не думаешь про тул** — думаешь про игру.

---

## Правило для агентов / дизайна

1. Новый рычаг / формула / «режим эксперта» — только если без него **ломается удобный жест**.
2. Сначала: правильный дефолт из справочника/правил (ячейки, КД, раса, слоты).
3. Потом: одна понятная донастройка (override), не язык формул.
4. Сверхнастройки LSS-стиля не копировать «на всякий случай».
5. Если фича есть у LSS, спросить: *это Android-крутилка или iPhone-удобство?* Бери только второе.

## Где это уже видно в продукте

| Жест | Почему это «iPhone» |
|------|---------------------|
| Ячейки «От класса» | Не считаешь таблицу PHB руками |
| КД от доспеха/щита | Надел — пересчиталось; override если надо |
| Раса из справочника | Скорость/ТЗ/языки сами |
| Каст с upcast + Conc в шапке | Как за столом, без конструктора |
| Play Desk режимы (Бой/Исслед./…) | Контекст сессии, не панель всех настроек сразу |
| Classic = тот же sheet | Не два персонажа «для печати» и «для игры» |

## Где ещё надо дожать удобство (не крутилки)

| Тема | Почему важно |
|------|--------------|
| Авто-ASI от расы | Сейчас цифры вручную — трение |
| Полнота каталога (закл./классы/предметы) | Иначе уходят в LSS/dnd.su mid-session |
| Бросок с листа → лента стола | Один жест, без настройки интеграций |
| Импорт из LSS | Переезд без боли |
| Калибровка генератора боя | USP мастера, пока не дожат |
| PDF одной кнопкой | Печать без сюрпризов |
