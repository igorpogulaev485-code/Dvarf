# Единый wizard онбординга (create + level-up)

Спека UX для слайса `cursor/guided-onboarding-wizard-ef23`.  
Цель: один проводник шагов вместо серии независимых попапов.

## Принцип

- **Один dialog**, внутри — очередь шагов.
- Шаг закрывается после выбора или **«Позже»** (бейдж «не выбрано» на умении).
- Expertise смотрит на **сводные владения** (фон + класс + раса + архетип + будущие черты).

## Create: фон → класс → раса → черта

Порядок согласован с Игорем (2026-10-08): предыстория = прошлое, класс = настоящее.

| # | Шаг | Зачем |
|---|-----|--------|
| 1 | **Предыстория** | Навыки/языки/инструменты/снаряжение с прошлого |
| 2 | **Класс** (+ старт с уровня N) | Навыки класса **без дублей** с фона (серые чипы «уже есть») |
| 3 | Expertise / fighting style / архетип / ASI… | Из сводных владений; при старте с N — все уровни ≤ N |
| 4 | **Раса** | После класса (class-first: кастер/метки/расовые списки) |
| 5 | **Черта** (если раса даёт с 1 ур.) | Каркас «скоро», пока каталог черт неполный |

При создании: toast + scroll на предысторию + wizard с шагом фона.

Старт с 13 ур.: после гранта класса HP/XP на N; wizard ведёт через choice/ASI до N.

## Level-up

Тот же движок, только новые обязательные выборы этого уровня (Expertise 6, ASI, invocations…).

## Раса / фон после выборов (довыбор)

1. Expertise не сбрасывается, если уже полная.
2. Если была «Позже» — после расы/фона wizard может снова предложить шаг.
3. Фон перед классом — основной путь; если класс взяли раньше — wizard поставит фон перед class_grant.

## Не в этом слайсе

- Полный каталог черт (только шаг-каркас).
- Полный sweep всех choice в паках.
- Деплой без «залей».
