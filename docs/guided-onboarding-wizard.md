# Единый wizard онбординга (create + level-up)

Спека UX для слайса `cursor/guided-onboarding-wizard-ef23`.  
Цель: один проводник шагов вместо серии независимых попапов (class grant → Expertise → ASI → …).

## Принцип

- **Один dialog**, внутри — очередь шагов (`pending feature choices` + ASI + грант класса).
- Шаг закрывается только после выбора или явного **«Позже»**.
- «Позже» не ломает лист: на умении остаётся бейдж **«не выбрано»**, добрать можно с умения или снова открыв wizard.
- Expertise смотрит на **сводные владения листа** (класс + раса + архетип + фон/черты, когда появятся), а не только на пакет умения.

## Create (class-first, как на проде)

При создании можно указать **стартовый уровень** (1–20). После гранта класса лист прыгает на N (HP по средним, XP на порог уровня), wizard набирает все незакрытые choice/ASI с `feature.level ≤ N`.

Типичный плут 1 ур.:

| # | Шаг | Что выбирает | Куда пишет |
|---|-----|--------------|------------|
| 1 | Класс: навыки / инструменты / снаряжение | грант старта | `class_grants` + skills/tools/inventory |
| 2 | **Предыстория** | каталог + развилки (навыки/языки/снаряжение/RP) | `background_grant` + skills/tools |
| 3 | Компетентность (1 ур.) | 2 из уже владеемых (класс **и** фон) + воровские инструменты | `feature_picks` + `skills[].is_expertise` |
| 4 | Архетип / покровитель (если умение-гейт уже открыто) | каталог архетипа | subclass grant |
| … | Прочие `choice` 1 ур. (fighting style у воина и т.п.) | option id | `feature_picks` |

Старт с 13 ур. (пример плута): грант → **предыстория** → Expertise 1 → архетип → ASI 4 → Expertise 6 → … в одном wizard.

Порядок: **владения класса → предыстория → Expertise/choice → ASI**. Раса по-прежнему после (class-first); довыбор Expertise после расы/фона, если была «Позже».

Раса по-прежнему **после** класса (class-first). См. ниже «Раса после класса».

## Level-up

Тот же движок, но в очередь попадают **только новые обязательные выборы** этого уровня:

| Триггер | Примеры шагов |
|---------|----------------|
| +1 уровень класса | Expertise 6, ASI 4/8/…, новый fighting style, +воззвания (добить count), pact boon 3 |
| Смена архетипа | revoke старых subclass picks/грантов (как сейчас) → очередь новых choice архетипа |
| Смена расы / фона | не сбрасывает уже записанную Expertise; см. довыбор |

Минус уровня (−1): picks умений с `level > новый` снимаются; `is_expertise` пересчитывается из оставшихся expertise-picks; ASI ledger как сейчас.

## Раса после класса (довыбор)

Зафиксированное решение MVP:

1. Expertise **не пересчитывается насильно**, если выбор уже полный.
2. Если Expertise была **«Позже»** (pick пуст) или недобрана — после гранта расы/фона wizard **может снова предложить** шаг: в пуле опций уже есть новые расовые навыки.
3. Если пользователь хочет заменить Expertise под новый навык расы — снимает/меняет pick на умении (inline или через wizard); лист синхронизируется.

Фон и черты: тот же стык, когда сущности появятся (владения попадут в сводный skill state → Expertise их увидит).

## Очередь `pending`

Умение с `choice` разблокировано и pick не удовлетворяет `max_picks` → шаг в очереди.  
ASI — отдельный kind шага (ledger `class_asi`), но **тот же** wizard, не второй UX.

Виды шагов MVP:

- `class_grant` — бывший ClassSetup
- `feature_choice` — fighting style, invocations, pact boon, Expertise, …
- `asi` — +2 / +1+1 (черта — каркас)
- `subclass` — мягкий шаг «выбери покровителя/архетип» (ведёт в существующий subclass flow)
