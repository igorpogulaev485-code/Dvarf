# Справочник: делаем ли «как dnd.su / ttg»?

**Статус:** позиция зафиксирована · не слайс кода  
**Связано:** B0 `content_layer` ✅ · playbook каталогов · `/legal`

---

## Короткий ответ

**Нет — отдельный публичный справочник «ещё один dnd.su / ttg» мы не строим.**

Справочники **остаются внутри КриD20** (лист + стол): бесплатно, для игры.  
Мы **не** позиционируемся как зеркало/клон dnd.su или ttg и **не** делаем отсылку «взято с ttg/dnd.su».

---

## Зачем так (простыми словами)

| Идея | Почему не берём |
| --- | --- |
| Свой сайт-энциклопедия «как dnd.su» | Конкурируем с справочниками и сами лезем в их поле; выше риск «плагиат базы» (щит 2) |
| В `/legal` или UI: «см. dnd.su / ttg, там бесплатно» | Признаём их как источник правды → как раз то, от чего уходим |
| Paywall на книги | Запрещено нашим режимом: каталог всегда бесплатен |

| Что делаем вместо этого | Смысл |
| --- | --- |
| `community_ref` внутри продукта, **бесплатно** | Охват книг для стола без продажи «доступа к PHB» |
| Короткий `/legal` + контакт | Куда писать по материалам |
| Позже B2: рвём следы парсеров ttg | Свой SoT, не зеркало |

Если понадобится **мягкая** публичная фраза (не сейчас, отдельный ok):  
«Справочные материалы в сервисе бесплатны и нужны для игры за столом» — **без** имён dnd.su / ttg / Wizards в маркетинге.

---

- Отдельный лендинг-энциклопедия — **не планируем**
