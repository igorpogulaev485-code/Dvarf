# B8 — Умный генератор боёв (продуктовый каркас)

Статус: **дизайн зафиксирован по ответам Игоря · код не стартовать до полного учёта сигналов листа**  
Ветка (когда код): `cursor/session-b8-generator-bacd` ← `cursor/session-b7-encounters-bacd`

## Проблема

dnd.su / сырой CR: «сложный» бой оказывается лёгким из‑за артефактов, расходников, способностей, заклинаний. Бюджет должен быть **честным под ярлык** (смертельный = смертельный).

## Жест мастера (1 экран)

1. Сложность → 2. Режим (сразу / волны) → 3. Локация → 4. **Тема/фракция** (мультивыбор + тумблер «похожие») → 5. Предложения (босс / пачка) → 6. «На стол» / в шаблон энкаунтера

## Входы

### Сложность (шкала продукта)

`Лёгкий | Средний | Сложный | Смертельный`

- Ярлык = реальный бюджет, без занижения.
- **Стартовая** формула бюджета: пороги XP из **DMG 2014** по уровням пати.
- Формула **точно изменится**: после разбора сигналов с листа пороги будут подниматься/сдвигаться (пати Игоря сейчас проходит «сложное» слишком легко).

### Режим

- **Сразу** — один блок «босс + пачка».
- **Волны** — N блоков «босс + пачка» (следующая волна = ещё один такой блок). Число волн без жёсткого лимита в продукте.

### Локация = `environment` бестиария

подземье · лес · город · горы · холмы · болото · равнина/луг · пустыня · побережье · полярная тундра · под водой · тропики · деревня · подземелья · руины · **любая**

### Тема / фракция (обязательный фильтр состава)

Мастер задаёт «кто это» — не только местность.

| Слой | Примеры | Источник в каталоге |
|------|---------|---------------------|
| Тип существа | нежить, исчадие, зверь, дракон… | `data.type_ru` / `type` |
| Подтип / племя | демоны, дьяволы, орки, гоблиноиды, кобольды, гноллы… | `data.subtype` |

**Мультивыбор** — несколько тем сразу (пример: орки + нежить; можно добавить демонов).  
Кандидат проходит, если попадает **хотя бы в одну** выбранную тему (OR).

**Тумблер «похожие»**
- **выкл** — только точное совпадение типа/подтипа;
- **вкл** — расширять каждую выбранную тему семейством (орк → гоблиноид/кобольд/гнолл; демон → другие fiend-подтипы и т.п.).

Чужие семейства не подмешиваются: если выбраны только орки и тумблер выкл — нежити в пуле нет; нежить появляется только если её явно отметили в мультивыборе.

### Пати — сигналы с листа (все must, релиз только когда все учтены)

- уровень, класс / подкласс  
- HP / КД  
- DPR (атаки, заклинания)  
- ресурсы (слоты, ярость, ki…)  
- магия / сопротивления  
- артефакты / расходники  
- напарники за столом  
- активные бафы на сессии  

Плюс анти-фейл: **летающие** (`speed.fly`) — не предлагать, если пати слабо против fly (нет надёжного ranged / своего fly / контроля высоты).

## Выход

- Роли: **босс** + **пачка** (не три роли волн).
- На роль: **2–3 кандидата** из бестиария; мастер выбирает.
- **Количество** в пачке считает продукт под бюджет сложности.
- Источник монстров: **только бестиарий** (не кастом-НПС лобби).
- Посадка: на стол сессии и/или сохранить как шаблон энкаунтера (B7).

## Инженерия (следующий шаг до кода)

1. Дизайн-док алгоритма: веса сигналов → множитель бюджета к DMG-порогам.  
2. Каталог «семейств» для «похожих» (орк / гоблиноид / …).  
3. Парсер сигналов с листа (что уже есть в sheet JSON vs что добрать).  
4. Eval-кейсы: пати Игоря × (лёгкий…смертельный) × (нежить / демоны / орки).

## Закрыто по UX темы

- Мультивыбор тем (орки + нежить + демоны — ок).
- Тумблер «только точные / с похожими».
