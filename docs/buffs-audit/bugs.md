## B01 — Нет модели активного эффекта и длительности
- **Ожидалось:** `sheet.combat.effects` с duration/mods/kind/slug; блок «Активные эффекты» на листе.
- **Фактически (до пачки):** только имя, источник, linked_concentration, опционально origin/ac_bonus.
- **Где:** `backend/app/services/sheet_effects.py`, лист Play Desk.
- **Записи:** сквозной
- **Пачка:** B-01
- **Статус:** исправлено — расширена модель, реестр mods, UI «Активные эффекты», кнопка «следующий раунд».

## B02 — Каст на союзника не доходит до цели
- **Ожидалось:** выбранные цели получают эффект на лист; Р25 на бэкенде; «Подмога» по русскому имени; лобби «Указание»/Благословение со структурой.
- **Фактически:** toast «целей N»; «Наставление» в подсказках; Aid только через «помощь».
- **Где:** `CastSpellDialog.tsx`, `sheetActions4.ts`, `allyTargets.ts`, `ApplyEffectDialog.tsx`
- **Записи:** B-007
- **Пачка:** B-01
- **Статус:** исправлено — `POST /characters/{id}/effects/apply`, каст пишет эффект, regex «Подмога», подсказка «Указание», share с mods.

- **Где:** `sheet_effects.clear_linked_effects_for_caster`, `sheetActions1/4`, HP pad
- **Записи:** сквозной
- **Пачка:** B-01
- **Статус:** исправлено — API clear-concentration (+ swap без сброса Conc), вызовы с листа, 0 хитов.
