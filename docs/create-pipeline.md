# Create pipeline (2014) — план после интервью

Отдельная страница создания персонажа. **2024** остаётся на текущем пути (лист + wizard).

## Вход

1. «Создать персонажа» → выбор редакции (как сейчас).
2. **2014** → `/characters/create` (новая форма).
3. **2024** → старый поток (лист + guided wizard).

## Пайплайн (сверху шаги)

Порядок зафиксирован:

1. **Раса** — карточки + поиск/фильтр источника; справа ASI/черты/расовые заклинания; имя персонажа; диалог подрасы/грантов.
2. **Черта** — только если раса даёт `featNoteRu`; иначе шаг пропускается автоматически. Каталог черт (если есть) + «отметить без каталога».
3. **Предыстория** — карточки + поиск/фильтр; справа умение фона и владения; диалог гранта.
4. **Класс** — фиксация класса **и сразу** `ClassSetupDialog` (навыки/инструменты/снаряжение). Анти-дуп навыков с расой+фоном. Пики в `classGrantPicks` сразу.
5. **Характеристики** — вручную / массив 15–14–13–12–10–8 / point buy (27 очков, max 15 до расовых). Расовые бонусы поверх базы.
6. **Прокачка** — развитие, **не** повтор стартовых навыков/снаряжения основного класса:
   - уровни классов, HP: L1 основного = max кости; далее среднее **или** бросок; первый уровень MC — не max;
   - архетип (`SubclassSetupDialog`);
   - GuidedWizard для L1+ feature choices / ASI / expertise (без `class_grant` старта);
   - мультикласс (пороги; prune при откате ASI/уровня);
   - заклинания;
   - панель **расовых условных эффектов** (racial_spells unlock / caster gate).

## Оболочка UX

- Отдельная страница; сверху шаги (черта скрыта, если не нужна).
- Слева — карточки текущего шага (+ поиск и source chips на каталожных шагах).
- Справа — **богатая** сводка из `catalog.data` + `resolve*GrantDef` / classFeatures packs (hit die, saves, навыки, доспехи/оружие, L1 умения, текст умения фона, ASI/traits расы).
- Назад: сбрасываются только поля **текущего** покидаемого шага.

## Черновик / Готово / F5

- F5: `localStorage` ключ `dvarf.createPipeline.v2` (`version: 2`). Старые v1-черновики сбрасываются.
- **Сохранить черновик** → БД `is_draft=true` → список («Черновик» + «Продолжить создание»).
- **Готово** → `is_draft=false` → цифровой лист.
- Жёсткий блок «Готово»: архетип (если гейт), Expertise/ASI по уровню, навыки/снаряжение класса, имя, характеристики.
- Спеллы: предупреждение «на листе / вернуться в форму».

## После создания

Level-up и мультикласс в кампании — **та же логика**, что блок «Прокачка».

## Справочники (проверено)

- Классы PHB+Artificer feature packs ×13, подклассы в паках.
- Расы PHB/MPMM/setting specs.
- Предыстории PHB catalog ~75.
- SRD 2014: spells 319, weapons/armor/items; feats в SRD почти пустые (Grappler) — шаг черты поддерживает «без каталога».

## Не в этом слайсе

- Новая форма для 2024.
- Деплой без «залей».
