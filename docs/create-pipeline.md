# Create pipeline (2014) — план после интервью

Отдельная страница создания персонажа. **2024** остаётся на текущем пути (лист + wizard).

## Вход

1. «Создать персонажа» → выбор редакции (как сейчас).
2. **2014** → `/characters/create` (новая форма).
3. **2024** → старый поток (лист + guided wizard).

## Пайплайн (сверху шаги)

1. **Предыстория** — карточки слева, краткое описание справа; грант фона.
2. **Класс** — только фиксация класса 1 ур. (без прокачки).
3. **Раса** — выбор вида/подрасы + грант; имя персонажа здесь; **черта** сразу после, если раса даёт (ситуационно).
4. **Характеристики** — три режима: вручную / массив 15–14–13–12–10–8 / point buy (27 очков, max 15 до расовых, таблица PHB). Подсказки приоритетов класса. Расовые бонусы поверх базы.
5. **Прокачка** — сюда уходит всё развитие:
   - умения 1 ур. (fighting style, Expertise, навыки/снаряжение класса…);
   - архетип;
   - ASI 4/8/…;
   - HP: L1 основного = max кости; далее среднее **или** бросок на каждый уровень; первый уровень вторичного класса — не max (как PHB/2024 SRD);
   - пакет снаряжения **или** стартовое золото;
   - заклинания кастеру;
   - крутилка уровней класса; сумма = уровень персонажа;
   - кнопка **мультикласс** (много классов): список с порогами / «не хватает Сил 2»; после ASI могут открыться новые;
   - минус уровня → проверка MC-порогов → предупреждение → снятие неподходящих MC.

## Оболочка UX

- Отдельная страница.
- Сверху — шаги пайплайна.
- Слева — карточки текущего шага; справа — краткое понятное описание (не полный TTG).
- Назад: сбрасываются только поля **текущего** покидаемого шага (пример: с характеристик на расу → только характеристики).

## Черновик / Готово / F5

- F5: `localStorage` черновик формы.
- **Сохранить черновик** → запись в БД с `is_draft=true` → список персонажей (метка «Черновик» + «Продолжить создание»).
- **Готово** → `is_draft=false` → цифровой лист.
- Жёсткий блок «Готово»: всё, что нельзя сменить без повышения уровня (архетип, Expertise, ASI, style, навыки класса, снаряжение старта, спеллы known-only-on-level-up…).
- Можно на лист без блока: то, что в игре пересобирается (например подготовка друида). Для таких спеллов — предупреждение «на листе / вернуться в форму».

## После создания

Level-up и мультикласс в кампании — **та же логика**, что блок «Прокачка».

## Справочники (проверено)

- Расы PHB/MPMM/setting specs.
- Предыстории PHB catalog ~75.
