### Входы в создание

1. **Список персонажей** (`CharactersPage` + `CreateCharacterButton`): «Создать персонажа». При открытом флаге — выбор редакции, иначе сразу 2014.
2. **Пустой список**: та же кнопка + `EDITION_HINT` + «Как это работает» (справка, не мастер).
3. **Карточка черновика** (`CharacterCard.tsx`): `href=/characters/create/:id` (доделывание 2014-черновика).
4. **Лобби** (`createHeroForLobbyHref` в `frontend/src/shared/api/lobbies.ts` ~1052–1065): `/characters/create?lobbyId=&code=` или `/characters/create/:characterId?…`. Текст кнопки: «Создать героя для этого лобби» (`CampaignRulesPanel.tsx` ~375 и ~619; `JoinLobbyPage.tsx` ~272–274; `CharacterDetailPage.tsx` ~550–555). Параметра редакции в ссылке **нет** — это вход в форму **2014**.
5. **Копия при конфликте лобби** (`JoinLobbyAction = 'copy'`, `CharacterDetailPage.tsx` ~253–259, 541): сервер отдаёт `cloned_character_id`, клиент открывает пайплайн 2014 с этим id «под правила старта» (комментарий L-16 в `CreateCharacterPage.tsx` ~662). Общего импорта/клона персонажа вне этого пути **нет** (`createCharacter` / `createCharacter2024` / `deleteCharacter` — без clone/import API).
6. **«Добро пожаловать»** (`WelcomeDialog.tsx`, копии `WELCOME` в `copy.ru.ts`) открывается на `/characters`, сегментирует тур («Я впервые в D&D / Играл, но тут впервые / Пропустить подсказки») и **создание не запускает**.

Гостю кнопки создания нет (нужен вход) — как в §23.
