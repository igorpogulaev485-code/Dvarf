Гибрид · две ровные полоски

Выбранный значок — только две горизонтальные полоски эталона (без третьей наклонной). Цвет чуть тусклее подписей: в светлой rgba(45,45,42,0.62), минимум 3,76 на шапке; в тёмной rgba(255,255,255,0.38), минимум 3,32 (норма для нетекста ≥3). Иконка в правом верхнем углу появляется только у плашки под курсором (150 мс) и у той, которую тащат. Тащить можно за любое место плашки.
