## Как пользоваться

Статусы:

| Статус | Смысл |
|---|---|
| **утверждён** | Игорь принял макет или явно назвал экран готовым / утверждённым |
| **утверждён, с оговоркой по кадрам** | экран принят, но комплект тёмных или 390-кадров неполный; в производство всё равно идёт этот макет |
| **в работе** | есть план или частичная вёрстка, приёмки макета ещё нет |
| **лобби — позже** | делать последним этапом, только после приёмки макетов лобби |
| **не утверждено / неясно** | нет решения, только рекомендация, или только запись в стратегию |
| **архив / не в прод** | исторические варианты и сравнения; хранить, не внедрять как целевой UI |

`kried20-concept-all.html` собран 20.11.2026 (группа «Утверждённое / актуальное» — 57 страниц, «Варианты и сравнения» — 88). В эту сборку **не входят** мобильный лист, мастер создания и классический лист — они приняты позже и живут в отдельных эталонах. Не делать вывод «раз в all-html нет — не утверждено».
