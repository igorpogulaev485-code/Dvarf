# Импорт мира (мастер и ИИ)

Как залить уже собранный мир (папка markdown, zip или публичная git-ссылка)
в **черновик сверки** Creed20/Dvarf, подтвердить его и откатить при ошибке.

Мир остаётся **частным**: только внутри лобби и сеттинга этого мастера.
Общего каталога, витрины миров и «поделиться миром» нет.

В этой версии импорта доступна только редакция **`rules_edition=2014`**.
Значение `2024` и любое другое — понятная ошибка `rules_edition_unsupported`,
без тихой подмены. Кнопка создания персонажа «D&D 2024» скрыта.

Подробности MCP: [`docs/world-import-mcp.md`](world-import-mcp.md).

Та же справка на сайте (для залогиненного мастера): [`/help/world-import`](/help/world-import).

## Кому доступно

| Кто | Что может |
|-----|-----------|
| Мастер в сессии (обычный вход) | Залить, сверка, подтвердить, отменить, токен, тумблер «ИИ может подтверждать» |
| Токен импорта (`Bearer wapi_…`) | validate / upsert / git / diff / confirm (если тумблер включён) / undo **не** умеет |
| Игрок за столом | Видит только уже раскрытое мастером; черновик импорта и сверку не читает |

Токен привязан к **одному лобби и одному сеттингу**. Чужие миры не читает,
тумблер не включает, пароль и биллинг не трогает. Сырой секрет показывается
мастеру **один раз**; в базе хранится только хеш.

## Как залить мир

1. Откройте сеттинг лобби → блок «Залить мир» (десктоп мастера, ориентир 1440×900).
2. Выберите способ:
   - **Файлы / zip** — markdown с YAML-шапкой как есть;
   - **Публичная git-ссылка** — HTTPS на github.com или gitlab.com (без `file://`, localhost и частных IP);
   - **MCP по адресу** — см. [`world-import-mcp.md`](world-import-mcp.md).
3. Сначала имеет смысл **проверить пакет** (`validate`) — в канон ничего не пишется.
4. Затем **залить в черновик** (`upsert`). Появится задание со статусом «к сверке».
5. На сверке смотрите статусы: новое / обновление / конфликт / нет в источнике /
   предложение ИИ. Конфликт мастер решает явно; отсутствующее **сами не удаляем** —
   помечаем и спрашиваем.
6. **Подтвердите** выбранные пункты. Тумблер «ИИ может подтверждать» по умолчанию
   **выключен**. Кто подтвердил — в журнал. Подтверждение можно **отменить** (undo),
   пока мастер не правил сущности вручную после confirm.
7. Повторная заливка **обновляет** по стабильному ключу источника, не плодит дубликаты.

Поле `rules_edition` можно не присылать — будет `2014`. Иное значение — отказ.

## Что принимает пакет

Тип карточки берётся из папки (и тега, если он есть). Стабильные id выдаёт Creed20.
Волна импорта: локации, НПС, фракции, квесты, лор, сессии, заметки, книги для игроков,
персонажи партии и PDF-листы, свои монстры и предметы со статблоками **2014**.

Не создаём собственные расы, классы, подклассы, заклинания и черты. Неизвестное имя
в листе остаётся текстом с пометкой «отложено до хоумбрю».

## Нейтральный пример пакета

Минимальный набор файлов (имена вымышленные, не учебный мир):

```text
world/locations/northern-post.md
world/npcs/watch-erna.md
world/factions/bridge-guard.md
world/lore/old-bridge.md
campaign/sessions/01-arrival.md
world/player-books/chapters/chapter-01.md
campaign/party/characters/arden.md
assets/character-sheets/arden.txt
```

Фрагмент карточки локации:

```markdown
---
title: Северный пост
tags: [location]
---

# Северный пост

Пограничная застава у реки.
```

Тело запроса (упрощённо):

```json
{
  "rules_edition": "2014",
  "files": [
    {
      "path": "world/locations/northern-post.md",
      "content": "---\ntitle: Северный пост\n---\n\n# Северный пост\n"
    }
  ]
}
```

## Ошибки API (для ИИ и мастера)

Ответ однообразный: `code`, путь (файл/поле), сообщение по-русски, подсказка «как исправить».
Не «голый» 500 на лимитах и плохих URL.

| Код | Когда |
|-----|--------|
| `rules_edition_unsupported` | Прислали не `2014` |
| `quota_exceeded` | Слишком много файлов в пакете |
| `file_too_large` | Файл / zip / git-архив больше лимита |
| `bad_encoding` / `bad_zip` | Нечитаемый текст или битый zip |
| `git_url_rejected` | Не HTTPS github/gitlab, localhost, частный IP, `file://` |
| `forbidden_setting` | Токен не для этого лобби/сеттинга |
| `import_in_progress` | Уже идёт разбор |
| `confirm_ai_disabled` | Токен хочет confirm, а тумблер выключен |
| `conflict_needs_review` | Есть конфликт без решения мастера |
| `undo_requires_master` / `undo_unsafe` | Undo только мастеру; после ручной правки — небезопасно |

Повтор `POST` с тем же ключом идемпотентности не создаёт второе задание.

## Приватность

- Существа, предметы и импортированные персонажи живут **в сеттинге мастера**.
  В чужом лобби и в общем каталоге правил их нет.
- Черновик импорта и экран сверки — только мастеру (и токену этого сеттинга).
- Игрок на телефоне видит только уже раскрытые страницы вики.
- MCP **не публикуем** в каталогах ChatGPT и Claude — мастер сам вставляет адрес и токен.

## Лимиты (ориентир)

Слишком большой пакет или плохой git-URL дают код ошибки выше, а не падение сервера.
Текстовые файлы и zip ограничены по числу файлов и размеру; git-архив — отдельным
потолком (см. сервис git-импорта). Если лимит мешает — уменьшите пакет или режьте
на части.

## Связанные экраны и каналы

- REST: `/settings/{setting_id}/world-imports/…` (отдельный роутер импорта мира).
- Zip / папка / git / MCP — те же черновик и сверка.
- Экран мастера (W-API-11): заливка, токен, сверка, тумблер.
- MCP: [`world-import-mcp.md`](world-import-mcp.md).

Деплой этим документом не запускается — только владелец через Actions «Deploy».
