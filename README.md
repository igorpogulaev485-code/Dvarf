# Dvarf

Лист персонажа D&D с раздельными **правилами** (`rulesEdition`) и **вёрсткой листа** (`sheetLayout`).

## Сейчас

- Вёрстка листа **2014** (3 страницы, близко к официальному WotC)
- Можно указать правила 2014 или 2024 (расчёты пока общие 5e)
- Текстовые блоки на экране **растут** с содержимым (не обрезают, как часто бывает в ЛСС)
- Печать / сохранение в PDF через браузер (Letter)

## Запуск

```bash
npm install
npm run dev
```
