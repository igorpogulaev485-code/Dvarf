## Для агентов (обязательно)

После **каждого** слайса, который реально попал в продукт (мерж / деплой / «залей на сервер»), **обнови этот файл в том же PR** (или сразу следующим коммитом в той же ветке).

### Когда писать

| Событие | Действие |
|--------|----------|
| Слайс задеплоен на Timeweb | Добавь/обнови пункты в разделе «Сейчас в продукте» |
| Фича есть в коде/PR, но **не** на сервере | Пиши только в «В ветках / ещё не на проде» |
| Фича сломана или частично работает | Честно пометь ⚠️ в пункте |
| Фича убрана / заменена | Удали или перенеси в «Убрано», не оставляй как будто жива |

### Как писать

1. Язык — **простой русский**, как для пользователя (не «JSONB sheet_version», а «лист не затирается, если открыт в двух вкладках»).
2. Пиши **что видит/может сделать человек**, не список файлов.
3. Один слайс → один короткий блок или несколько буллетов в нужной секции.
4. В конце блока укажи: дата (UTC), ветка/PR, «на проде: да/нет».
5. **Не** копируй сюда секреты, пароли, токены, содержимое `.env`.
6. Не раздувай roadmap — очередь и backlog только коротко внизу.
7. Если не уверен, на проде ли фича — проверь URL/`/health`/UI, потом пиши.

### Шаблон записи (копируй)

```markdown
### YYYY-MM-DD — кратко что сделали
- …
- …
На проде: да/нет · ветка `cursor/…` · PR #N
```

## Сейчас в продукте (прод)

> Живой сервер. Агенты дополняют и правят ниже.

### Аккаунт
- Регистрация по email + пароль: **обязательный никнейм**, письмо с подтверждением — без клика по ссылке вход закрыт
- Вход по email + пароль
- Сброс пароля («забыли пароль») — письмо на почту (SMTP Mail.ru)
- Личный кабинет:
  - никнейм, ФИО, телефон (маска +7)
  - email только для просмотра; смена — отдельным блоком (письмо-подтверждение уходит на **текущую** почту)
  - загрузка / удаление аватара
  - смена пароля
  - сессии: список устройств, завершить одну / остальные / выйти везде
  - опасная зона (красным): необратимое удаление аккаунта
- На главной со списком персонажей — миниатюра аватара и никнейм (клик → кабинет)
- Кнопки Яндекс / VK на экране входа и в кабинете: **пока заглушки** (привязка/отвязка — следующий срез, нужны ключи)

### Персонажи
- Список персонажей
- Создание персонажа (редакция правил 2014 или 2024)
- Открытие цифрового листа
- Данные хранятся на сервере (не только в браузере)

### Цифровой лист
- Боевая шапка: КД, скорость, хиты, инициатива, вдохновение, состояния, истощение, спасброски от смерти
- Имя, уровень, опыт, раса/класс (справочник или свой текст), подкласс, предыстория, мировоззрение
- Характеристики, спасброски, навыки (владение / экспертиза)
- Пассивные чувства, тёмное зрение, владения доспехами и оружием
- Короткий и продолжительный отдых, кости хитов, временные хиты
- Свои ресурсы с пипсами (сброс на отдыхе)
- Атаки: оружие / артефакт из каталога или вручную
- Инвентарь: монеты, вещи, вес, лимит СИЛ×15, перегруз
- Настройка магических предметов (до 3)
- Заклинания: ячейки, подготовка, каст, гримуар (sample), pact magic
- Текстовые блоки: переименовать / скрыть / добавить / ↑↓
- Синхронизация вкладок + предупреждение при конфликте версий

### Лобби / стол
- В интерфейсе есть: список лобби, создание, вход по коду/QR, сеттинги, сессии, посадка персонажей за стол
- ⚠️ На проде UI лобби уже в бандле; прокси nginx для `/lobbies` / `/settings` / `/sessions` нужно проверить — API может не отвечать (405 / HTML вместо JSON)

### Справочник (seed на сервере)
- Расы, классы (пока мало), оружие, снаряжение/артефакты, заклинания (sample), состояния SRD

### Инфра
- Прод на Timeweb VPS: http://201.34.132.252/
- Стек: React + FastAPI + PostgreSQL (Docker)
- Почта: SMTP Mail.ru на проде (исходящие порты 465/587 открыты; после смены тарифа Timeweb может снова закрыть)
