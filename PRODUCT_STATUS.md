## Для агентов (обязательно)

После **каждого** слайса, который реально попал в продукт (мерж / деплой / «залей на сервер»), **обнови этот файл в том же PR** (или сразу следующим коммитом в той же ветке).

### Когда писать

| Событие | Действие |
|--------|----------|
| Слайс задеплоен на Timeweb | Добавь/обнови пункты в разделе «Сейчас в продукте» |
| Фича есть в коде/PR, но **не** на сервере | Пиши только в «В ветках / ещё не на проде» |
| Фича сломана или частично работает | Честно пометь ⚠️ в пункте |
| Фича убрана / заменена | Удали или перенеси в «Убрано», не оставляй как будто жива |

### Как писать

1. Язык — **простой русский**, как для пользователя (не «JSONB sheet_version», а «лист не затирается, если открыт в двух вкладках»).
2. Пиши **что видит/может сделать человек**, не список файлов.
3. Формат пункта: **функция → как работает → какой эффект получает пользователь**.
4. Один слайс → один короткий блок (таблица или буллеты) в нужной секции.
5. В конце блока укажи: дата (UTC), ветка/PR, «на проде: да/нет».
6. **Не** копируй сюда секреты, пароли, токены, содержимое `.env`.
7. Не раздувай roadmap — очередь и backlog только коротко внизу.
8. Если не уверен, на проде ли фича — проверь URL/`/health`/UI, потом пиши.

## Сейчас в продукте (прод)

> Стартовый срез по живому серверу. Агенты дополняют и правят ниже.

### Аккаунт
- Регистрация и вход по email + пароль
- Сброс пароля («забыли пароль»)
- Личный кабинет: отображаемое имя, ФИО, телефон
- Выход из аккаунта
- Кнопки Яндекс / VK на экране входа (VK — заглушка; Яндекс — если ключи настроены)
- ⚠️ Смена email, загрузка своего аватара, список устройств / «выйти везде» — на этом проде пока нет (есть в отдельных ветках кабинета)

### Персонажи
- Список персонажей
- Создание персонажа (редакция правил 2014 или 2024)
- Открытие цифрового листа
- Данные хранятся на сервере (не только в браузере)

### Цифровой лист
- Боевая шапка: КД, скорость, хиты, инициатива, вдохновение, состояния, истощение, спасброски от смерти
- Имя, опыт, предыстория, мировоззрение
- **Уровень и классы (мультикласс)** — кнопка «+1 уровень» спрашивает: качать уже взятый класс или взять 1 уровень другого; на листе видны строки классов (например «Воин 3 / Волшебник 2»), суммарный уровень и бонус мастерства считаются от суммы
- **Раса из справочника** — выбор расы подставляет скорость, тёмное зрение, языки, размер и короткий текст особенностей; характеристики (ASI) пока пишутся в тексте, цифры на листе не меняются сами
- Размер персонажа (можно поправить вручную после выбора расы)
- Подкласс у каждого класса отдельно
- Характеристики, спасброски, навыки (владение / экспертиза)
- Пассивные чувства, тёмное зрение, владения доспехами и оружием
- Языки и инструменты (пресеты + свой текст)
- Короткий и продолжительный отдых, кости хитов, временные хиты
- Свои ресурсы с пипсами (сброс на отдыхе)
- Атаки: оружие / артефакт из каталога или вручную
- Инвентарь: монеты, вещи, вес, лимит СИЛ×15, перегруз; КД от надетого доспеха/щита (ручной override как у инициативы)
- Настройка магических предметов (до 3)
- Заклинания: ячейки и лимит подготовки от класса/уровня (2014), подготовка, каст с upcast, концентрация в шапке, гримуар (sample), pact magic; при мультиклассе ячейки по правилам caster level
- Текстовые блоки: переименовать / скрыть / добавить / ↑↓
- Синхронизация вкладок + предупреждение при конфликте версий

### Лобби / стол
- В интерфейсе есть: список лобби, создание, вход по коду/QR, сеттинги, сессии, посадка персонажей за стол
- ⚠️ На проде UI лобби уже в бандле; прокси nginx для `/lobbies` / `/settings` / `/sessions` нужно проверить — API может не отвечать (405 / HTML вместо JSON)

### Справочник (seed на сервере)
- Расы 2014 с эффектами: человек, дварф, эльф, полурослик, гном, полуэльф, полуорк, тифлинг, драконорожденный, орк (упрощ.)
- Классы (пока мало), оружие, снаряжение/артефакты, заклинания (sample), состояния SRD

### Инфра
- Прод на Timeweb VPS: http://201.34.132.252/
- Стек: React + FastAPI + PostgreSQL (Docker)

### 2026-10-06 — мультикласс + эффекты расы

| Функция | Как работает | Эффект для пользователя |
|--------|--------------|-------------------------|
| Повышение уровня | На листе жмёшь «+1 уровень» → выбираешь «Этот класс» или «Мультикласс» | Не надо вручную крутить цифру уровня: либо +1 к уже взятому классу, либо появляется второй класс с 1 уровнем |
| Список классов | У каждого класса свои уровни, название и подкласс; можно −1 у класса | Видно точный билд (например «Воин 3 / Волшебник 2»); суммарный уровень и мастерство считаются сами |
| Ячейки при мультиклассе | При смене классов/уровней ячейки пересчитываются по таблице 2014 (full + half/2; pact отдельно) | Не нужно вручную подгонять слоты под мультикласс-билд |
| Выбор расы из списка | Берёшь расу из справочника (не свободный текст) | Сразу подставляются скорость, тёмное зрение, языки, размер и блок особенностей |
| Смена расы | Старые «расовые» языки снимаются, свои добавленные языки остаются; текст особенностей расы обновляется | Можно передумать с расой без ручной чистки всего листа |
| ASI от расы | Бонусы характеристик описаны в тексте особенностей | Пока сам вписываешь цифры в характеристики (авто-ASI — позже) |
